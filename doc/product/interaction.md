# 通用交互与自适应

页面、表单、菜单和反馈共用以下交互要求：

- 主要操作、卡片内的独立按钮及错误详情入口，分别有明确标签、键盘焦点和至少48逻辑像素的触控区域。
- 等待、刷新或失败时，保留正文、所选对象和阅读位置；动态数值及时更新。
- 布局按当前窗口、局部约束、字号、安全区及键盘重排，保留同一任务和草稿。
- 首层反馈显示操作结果与已发生影响，完整技术内容在详情中阅读和复制。

各功能的具体状态和操作见[产品任务](overview.md#功能范围)。

## 界面与信息表达

背景、正文和基础控件以中性色为主，主强调色用于选中、焦点和主要操作。类别、状态、数据系列、配置图片和emoji保留各自颜色。同类控件使用一致的排版、间距、形状和过渡。

浅色和深色主题分别调整明度与对比度。未选中与禁用使用不同样式，只有禁用控件才采用禁用色。DIRECT使用类别色，安全或成功由对应操作状态说明。

品牌色为朱砂`#B84236`、石绿`#1A7A64`和钴蓝`#2858AF`，默认以朱砂为主，其余两色辅助。背景和前景颜色根据浅深主题及对比度调整。切换主强调色时，改变三色的主辅关系，业务颜色含义保持不变；类别图标、配置图片和emoji保留原有颜色，大面积正文使用中性色。

界面复用 Flutter Material 3、项目主题和 SDK 基础组件。正文、输入和关键数据所在区域保持背景稳定；互斥选项使用菜单或单选列表。[Android 小组件启停](runtime-and-strategies.md#桌面小组件)使用分段胶囊控件。

### 字体与选择

使用 Material 3 `TextTheme`：页面主要标题为 `titleLarge`，分组和列表标题为 `titleMedium`；列表名称与输入为 `bodyLarge`，正文为 `bodyMedium`，辅助信息为 `bodySmall`；按钮与菜单操作为 `labelLarge`，导航标签为 `labelMedium`。流量和状态的大号数值使用 `headlineMedium`。日志、YAML 和技术详情使用基于 `bodyMedium` 的 monospace，动态数字使用等宽数字。

配置卡、策略成员和同类内容单选的名称在选中时使用 `w700`，未选中使用 `w400`，同时保留背景或边框及选中语义；导航选中使用 `w600`。名称中的文字和 emoji 保持同一字符串。类型图标保留原有含义，不用悬空图标、叠加标记或重复文字表示选择。

搜索复用同一输入组件，保留调用方的输入、焦点、selection 和 composing；工具栏搜索在输入非空时先清空，输入为空时退出。页面内搜索清空后保留焦点。所有文字测量使用当前样式、语言、方向及实际 `TextScaler`，包括 Android 非线性缩放。

标题使用简短动作，长对象名放在正文中，操作后果靠近确认按钮。长名称、URL和技术内容自然换行，或在限定高度内滚动；用户始终能找到保存、关闭和错误详情。列表突出对象与状态，表单按字段分节，技术正文限制最大阅读宽度。

## 布局连续性

**窗口、字号、语言和用户操作不变时，等待、成功、失败、重试、普通选中、禁用及刷新不改变正文、工具栏和按钮布局。** 加载与刷新在已有控件内显示进度，需要反馈的操作结果和读取异常使用所属工作区的 floating SnackBar。正文不增删提示行，也不为错误、未显示的说明或浮层预留高度和宽度。

内存、速度、流量和时长在已有数据区域内更新，运行状态采用简短标签；完整错误由用户点击“错误详情”打开。列表更新保留仍存在的可见条目及其在屏幕中的位置，长值在所属区域展开或滚动。

实际内容编辑、条目增删、展开／收起、类型切换、打开详情，以及窗口、字号、语言、安全区和键盘变化按当前内容重排。仅测量当前语言和实际内容，不按全部候选状态或其他语言的最大文案永久占位；过渡保留焦点与阅读位置。

页面、详情、编辑器、设置、存储、DNS、许可及系统功能页面使用一致的过渡。应用自有浮层的开合、内容显隐、展开收起、状态变化、页面切换和布局调整采用短促、连续的动画。快速反向操作从当前画面继续，连续调整窗口时跟随最新尺寸，不积压动画或停在旧尺寸后跳变。SDK路由、菜单和Dialog直接使用已有动画；页面切换不重复创建仍在使用的业务组件。

输入、输入法组合文字、光标、滚动、拖拽和实时数字立即响应；引起布局变化时，仅对相应布局做过渡。页面或控件开始关闭时，立即停止响应、移除焦点和读屏内容，旧回调不再发起操作。停止和取消立即执行，业务记录在结果返回或I/O结束时更新。系统减少或停用动画时允许直接切换，应用不另设动画开关。

## 主题与语言

外观为系统／浅色／深色，语言为系统／中文／English，主强调为朱砂／石绿／钴蓝。新空数据默认系统外观、系统语言和朱砂；系统语言不匹配时回退English，已有偏好保持。

初始化先取得偏好再绘制对应主题。主题／语言切换保留任务、草稿、搜索、焦点和滚动，VPN及局域网服务继续运行。应用消息采用当前语言；用户正文、名称、日志、协议标识及法律原文保留原文。Android通知采用应用语言，渠道名保持稳定；系统文件选择器及VPN设置由系统自身呈现。

## 窗口与任务

窗口的宽和高分别参与布局计算，同时考虑局部父约束、实际TextScaler、安全区和键盘。窗口尺寸档作为设计参考。物理px、Flutter逻辑像素、Android dp和sp分别计量；每处insets由负责该区域的父组件处理一次。

| 宽度档 | 逻辑宽度基线 | 正常空间的设计 |
| --- | --- | --- |
| Compact | <600 | 完整窄窗导航、单列或上下正文、逐页详情及窄窗表单／浮层 |
| Medium | ≥600且<840 | 先满足导航、阅读与操作，局部空间充分时并排 |
| Expanded | ≥840且<1200 | 两区都可用时组织集合／详情、总览及表单章节 |
| Large | ≥1200且<1600 | 协调导航、工作区和局部操作，限制超宽内容与操作距离 |
| Extra-large | ≥1600 | 限制工作区和技术正文的最大宽度，保持分区稳定 |

高度分为Compact（<480）、Medium（≥480且<900）、Expanded（≥900）。各宽度档都检查高度较小或较大、大字号和键盘出现时的布局，复用同一任务与页面结构。

### 推荐窗口与紧凑布局

常规导航以280×280逻辑像素内容区为布局基线，计量区域为当前Flutter窗口扣除MediaQuery安全区后的可用区域。Bar为正文预留160逻辑像素高度，Rail为正文预留280逻辑像素宽度；中英、大字号和非线性TextScaler按实际文字测量决定常规导航容量。入口和正文在空间不足时使用紧凑导航与滚动布局。

Android Activity声明280dp最小宽度和360dp最小高度，为系统装饰保留纵向预算；应用不据此隐藏页面或阻止操作。窗口装饰、Flutter逻辑区域和Android dp分别计量，系统分屏仍可能在声明下限以下裁剪，裁剪由系统窗口管理。

空间不足时使用紧凑导航、单列和滚动，仍可停止、导航、编辑及查看错误。紧凑导航显示总览／策略／设置图标、语义标签和提示，横向不足时滚动。键盘和窗口变化实时更新可用约束，任务、草稿、选区／composing及运行状态保持。

### 导航容量与任务身份

导航形式和项数分别计算。可用逻辑宽度小于600或高度小于480时优先Bar；宽高均足够时尝试Rail。Bar按横向空间计算入口数量，并为正文保留高度；Rail按纵向空间计算入口数量，并为正文保留宽度。尺寸来自当前窗口和容器约束，扣除安全区与viewInsets，不按物理分辨率、设备类型或横竖屏标签判断。

设置目录提供全部任务，常驻导航按容量展开以下高频入口：

| 容量 | 顺序 |
| --- | --- |
| 3项 | 总览／策略／设置 |
| 4项 | 总览／策略／连接／设置 |
| 5项 | 总览／策略／连接／配置／设置 |

导航采用简短标签：连接任务显示“连接”／“Connections”，配置任务显示“配置”／“Configs”；页面标题分别保留“最近连接”／“Recent connections”和“配置管理”／“Configurations”。Bar展开四项或五项时，每项至少预留120逻辑像素，且选中与未选中标签均须单行完整显示；核心三项保留64逻辑像素的最低宽度预算，大字号下按实际高度换行。标准字号且没有横向inset时，Bar在480逻辑像素宽度起尝试四项，600起尝试五项。Rail按各项文字高度、最小行高和间距计算纵向容量。

120逻辑像素是本应用的导航密度要求。实际项数继续受字号、语言、安全区及正文空间限制；空间不足时收起入口或转为紧凑导航，设置目录继续到达同一任务。

每个导航目的地使用固定标识，设置目录与常驻入口共用任务、控制器和读取请求。窗口、字号或安全区变化时重新布局，保留草稿、搜索、焦点、选区、输入法组合状态及仍可见的列表项。打开页面、即时生效的偏好、文件导入导出分别使用对应操作；离开编辑页时，未保存修改只确认一次。

冷进入和系统“打开连接控制”统一指向总览。导航先完成编辑退出保护，取消后保持当前任务；紧凑窗口也沿同一导航流程。布局调整只改变呈现，任务历史由实际导航操作维护。

## 可见性与交互

当前任务仍可见且应用在前台时，总览、连接列表及仍可见的连接详情继续读取必要状态，窗口失焦只暂停输入、快捷键、语义动作和装饰动效。隐藏、最小化或被覆盖区域暂停相应UI读取；AppRuntime的后台采样继续运行。恢复交互后再检查当前页面及操作owner是否仍有效，退出动画中的旧页面不恢复操作资格。

新错误、操作结果和详情切换在窗口可交互时显示。失焦期间保留已完成操作的结果，恢复后由原页面显示；原页面已关闭时交给全局反馈。DNS查询成功后自动显示结果；明确关闭DNS工具后，旧回调不再打开工具或发起操作。

## 集合与详情

列表与详情都有足够空间阅读和操作时并排，否则逐页显示。首次进入不选中对象，点击列表项后才读取和展开详情。刷新或插入保留原选择；筛选排除所选对象时，详情继续显示并说明它不在当前列表中。对象删除、原会话结束或原文件被替换后，保留可复制内容，禁用对原对象的修改。

打开、关闭与单／双区拆合采用连续尺寸、位置或透明度过渡，保留同一对象、Controller和当前阅读位置。普通对象在宽窗为右侧详情保留固定宽度，开启、替换和关闭只过渡右区内容，主列表不随普通开合变宽；关闭回到无选择占位。只有实际窗口容量引起的分栏拆合才改变两区布局，设置页不套用对象详情规则。关闭开始即撤销点击、键盘与语义，快速反向续接当前状态；系统减少动态时可即时切换。

并排时列表与详情都继续更新，只有被其他页面覆盖的区域才暂停展示读取。同名对象被替换后按新对象处理；异步回调核对对象、运行会话、分页来源和存储版本。

## 表单与技术阅读

复杂节点、策略组和provider按完整章节组织，充分空间可并排相关章节；长证书、表达式和集合按需跨区。窄窗恢复明确顺序，保持同一Form、草稿、控制器、类型和嵌套记录。短规则、命名和单键值保持单列。嵌套列表按实际编辑区、键盘、安全区及保存动作预算，保持惰性构建。

表单先校验完整草稿，再按字段名及嵌套记录ID展开章节，滚动到第一个错误。输入框通过不增高的错误样式和语义关联对应错误，提交时沿首错定位流程显示一次 SnackBar；字段下不插入错误文字行，输入期间不随每个按键重复提示，修正后清除对应错误状态。修正和重试保持可用，保存中状态显示在原按钮内。技术内容连续显示并支持滚动阅读，短属性按内容自然排列。

设置在任何窗口下都没有并排详情区。复用 ReadingList，明确各组内容及统一组间距，保持阅读位置，窄窗单列，充分空间按完整分组成对双列；组内自然高、同行顶部对齐、整页共用滚动，不按内容高度重新平衡列归属。窗口、字号、语言、安全区或键盘变化时直接使用新布局；从二级页返回保留设置分组的位置和滚动。页面、即时偏好和文件动作保留各自语义，打开／关闭 DNS Dialog 不改变设置分组排布。

设置从上到下按以下顺序排列：

| 分组或入口 | 内容与顺序 |
| --- | --- |
| 外观与语言 | 外观、主题主色、语言 |
| 连接行为 | 运行模式、切换后重新连接 |
| 配置与数据 | 配置管理、插件（复写）、内核运行时配置、存储与数据 |
| 路由与资源 | 代理节点、全部策略组、规则、外部资源 |
| 诊断工具 | 最近连接、内核日志、DNS工具 |
| Android | 应用访问VPN控制、Always-on |
| 关于入口 | 打开关于页；隐私与许可、第三方许可位于该页内 |

“关于”是页尾独立入口，使用低对比surface、圆角边界及标准组间距，不作为Android组的子项或无标题网格单元，也不以额外空白区分。设置和常驻导航中的相同目的地共享任务身份、控制器及读取链。

## 菜单与反馈

同类选择使用共享 ChoiceMenuButton 和 Material MenuAnchor／MenuItemButton。菜单宽度按完整标签、字号、图标和内边距测量；SDK 结合工作区、安全区、键盘和铰链决定位置。长标签按词边界换行，长菜单内部滚动。选中项使用背景、`w700` 和选中语义，未选中为 `w400`；不预留对勾位置。菜单关闭后，触发按钮仍存在时将焦点还给它；开始关闭时立即停止响应并移除焦点和读屏内容。每次打开都记录当前对象与按钮位置。图标和颜色辅助区分操作，完整标签说明具体动作；DNS 清理菜单见[诊断规范](diagnostics.md#dns与fake-ip清理)。

| 结果类型 | 显示位置 |
| --- | --- |
| 正常等待、刷新、已有直接可见结果的普通成功 | 原控件及数据区域，不重复提示 |
| 需反馈的保存结果、失败、重要部分完成及重试结果 | 所属工作区的 floating SnackBar |
| 自动读取异常 | 共用 floating SnackBar，按来源及连续失败周期去重 |
| 字段校验 | 对应字段的错误样式与语义；提交时定位首错并显示一次 SnackBar |
| 删除、覆盖及其他真实确认 | 保留具体操作的确认Dialog |
| 完整错误及技术原文 | 用户点击“错误详情”后打开Dialog |

启停问题保留实际运行状态，单条操作错误归所属操作。首层摘要说明实际保存、应用或恢复结果，不自动打开技术详情。

floating SnackBar 位于 NavigationBar 上方或 NavigationRail 右侧工作区底部，在所属工作区居中，最大宽度560逻辑像素。摘要最多两行，详情、重试及关闭动作按实际宽度和 TextScaler 排列，操作可换行。键盘、安全区或局部高度不足以容纳完整提示时暂缓显示，不改变输入焦点。

同一来源持续读取失败不重复展示；关闭、滑动关闭或查看后保持安静，明确成功读取后才允许下一轮故障提示。不同有效提示按发生顺序显示；详情打开期间暂停队列，关闭详情后不重新显示原提示。切任务或来源失效时撤下旧提示和回调；高度不足、暂时被弹窗覆盖或失焦时保留有效队列，恢复后再显示。操作结果沿原operation identity反馈一次，SnackBar实际呈现时才确认本地feedbackOwner或全局结果已处理，不在入队时提前消费。策略成员浮窗持有本次选择的反馈owner，浮窗提前关闭则交回全局，底页不再重复呈现同一失败。

自动提示不改变输入焦点、selection 或 composing，不新增全局 Escape 行为。浮层短暂覆盖底部正文，关闭后末行和详情末尾完整可读；关闭不清除业务错误。错误详情读取点击时捕获的实际原因，不被后续读取改写。连接读取流程见[连接规范](connections.md#读取状态与错误详情)。

首层分别说明本次保存或恢复是否完成、连接是否建立及可执行下一步；点击“错误详情”查看本次失败。技术层保留操作返回的实际错误、`stack`、`cause` 和 `suppressed`，提供完整复制。配置与插件 YAML、运行时配置 YAML、日志原文和 DNS 记录可继续阅读，其他诊断页面不提供完整响应的展示入口。短内容紧凑，长内容可选择和滚动，关闭及详情动作持续可达。

## 输入与可访问性

触控目标至少48逻辑像素，SDK输入、焦点、选择、hover、语义和系统返回能力完整保留。Tab／Shift+Tab沿真实可用操作遍历，Enter／Space按控件语义执行；卡片主动作与更新、编辑、更多等子动作各有独立焦点，禁用或已退场内容不进入遍历，也不接收旧快捷键。正文采用真实TextScaler，包括非线性缩放；浅深主题核查前景配对，普通文字原则上至少4.5:1，大字与必要非文本控件按相应WCAG要求检查。状态同时用文字或形状表达，焦点清楚可见。

搜索保留原始输入和输入法组合状态，另外计算有效查询。X先清空非空输入并保留焦点，输入已空时退出搜索。返回先收起键盘，再按任务规则退出搜索。Ctrl／Cmd＋F用于搜索或查找，Ctrl／Cmd＋S保存，Escape逐层关闭；快捷键与按钮使用相同的对象检查、禁用条件和未保存修改确认。

## 设计依据

输入与可访问性参考Flutter[输入](https://docs.flutter.dev/ui/adaptive-responsive/input)、[可访问性](https://docs.flutter.dev/ui/accessibility-and-internationalization/accessibility)与[性能原则](https://docs.flutter.dev/perf/best-practices)。分区参考[Fluent布局](https://fluent2.microsoft.design/layout)，层次与连续性参考Apple[Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)，通过现有Material组件实现。
