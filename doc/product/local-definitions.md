# 本地定义与完整GUI

本规范覆盖节点、策略组、规则、proxy-provider和rule-provider的创建、查看、重开编辑及受限删除。各分类同时呈现真实运行属性和直接本地定义；可编辑原文与实际加载投影分别表达。

## 载体与入口

GUI写入以角色和随机ID识别的全局“本地自定义”插件。首次成功保存创建，默认启用、前置合并并置顶；后续操作维持其启停、位置和模式。普通插件列表可编辑、改名及整体删除；重建时生成新ID，表单提交始终核验捕获的记录身份。

| 分类入口 | 任务 |
| --- | --- |
| 代理节点 | 创建节点；直接本地节点重开编辑／删除 |
| 全部策略组 | 创建组、查看属性和贡献；直接本地组重开完整表单 |
| 规则 | 创建、重开及原位删除直接本地规则；集合内容与provider定义分别管理 |
| 外部资源 | 创建、重开及删除直接本地两类provider |

各分类直接管理载体停用、被覆盖、未参与运行及预览待确认的本地定义。搜索同时覆盖运行投影与本地原文，按来源及路径区分对象。

## 节点类型与字段

GUI新建提供24种固定原始type，原始parser另支持包含4种built-in在内的28种type。类型选择为独立纵向分组单选页，整行命中、右侧勾选，采用现有Material主题；选中返回原表单，保留共同字段和未提交输入。

| 分类 | 新建类型 |
| --- | --- |
| 标准代理 | HTTP、SOCKS5、SSH、MASQUE |
| 社区代理 | Shadowsocks、ShadowsocksR、VMess、VLESS、Snell、Trojan、Hysteria、Hysteria2、TUIC、ShadowQUIC、gost-relay、Mieru、AnyTLS、Sudoku、TrustTunnel |
| VPN | WireGuard、OpenVPN、ZeroTier、EasyTier、Tailscale |

每个新建type对应一行，HTTPS／SOCKS5-TLS通过各协议TLS字段设置。direct／dns／reject／rematch沿文本导入、已有定义与原始parser处理，新建范围由上表定义。

表单用文本、数值、布尔、选择和可增删集合覆盖实际依赖的公开Option及有效嵌套分支，表达式和编码字符串保留文字输入。可选值精确区分未设置、false、0与空值，数字标单位，字符串列表映射保留原类型。

Tailscale新建独立相对身份目录，改名、更新、停止和定义删除均保留其身份生命周期。认证与协议实网状态由实际会话确认，字段保存和parser构造分别结算。

## 策略组与provider

组类型为select、url-test、fallback、load-balance，完整提供公共及专属字段，包括default-selected、tolerance、strategy、hash-key。proxies与use分别编辑，引用保留原声明，循环及依赖检查交内核。

| 类型 | 需要保留的输入结构 |
| --- | --- |
| proxy-provider | http／file／inline；来源、path、interval、过滤、限额、header、health-check、override和payload |
| rule-provider | http／file／inline；domain／ipcidr／classical，yaml／text／mrs；MRS不配classical |

HTTP／file的payload按上游后备内容处理；inline节点复用完整子表单，只改父草稿，父保存时发布。header保留字符串列表映射，rule-provider format定义外部编码；RULE-SET作为独立规则引用维护。

provider路径为受管目录内的可选相对路径。HTTP缺失／空path时按公开规则派生，显式安全path保留；HTTP和file均检查遍历、符号链接与业务／身份目录冲突，错误关联对应字段。

## 规则

规则覆盖所接入内核公开类型与参数：普通规则为类型／匹配值／目标，MATCH仅需目标；RULE-SET引用provider，SUB-RULE引用子规则集，AND／OR／NOT保留原生条件。PROCESS／UID字段与Android实际归属能力分别核验。

条件与正则内逗号保留原生字符串，只处理外层字段和参数；新增规则放专用正文列表开头，重复项保留原索引，引用保留原合法表达。

[连接辅助入口](connections.md#从连接新增规则)使用可信同会话域名／后缀及真实单地址IP，目标为有效全部组与DIRECT／REJECT。原始定义的编辑权继续按独立原文身份判断。

## 重开与原文保留

各类完成创建→离开页面→重开→修改→保存→再次重开，表单由专用正文完整原文和直接路径回填，运行投影保留独立阅读身份。

保存按实际修改路径保留位置、未知未触碰字段、注释、格式及false／0／空值；provider改名保留邻接顺序，重复规则按索引替换。同名下层对象沿合成覆盖，专用正文内重名拒绝并保留输入。

alias、继承、未知type或控件表达范围以外的目标保留原文／草稿并给具体原因，无关分支继续可编辑。局部修改机制见[来源与本地编辑](../architecture/data-and-operations.md#来源与本地编辑)。

## 来源与可写性

可写权由专用项ID／revision／storage epoch、完整原文和路径共同确定。冲突、删除重建与整体恢复撤销旧写身份，保留输入供复制或明确重新编辑。

来源展示聚焦实际插件贡献：单来源使用加载时名称，多来源在属性页列出有序贡献。本地自定义独立标识，全部策略组卡片以20逻辑像素固定槽内的插件图标表达参与情况，Tooltip和语义提供含义；卡片进入定义属性，日常成员选择使用策略页入口。

provider定义贡献与下载成员来源分开，直接本地定义保留其独立编辑入口；本地原文和运行属性分别阅读。远程、内置及生成内容采用结构化只读字段，缺原始数据明确显示仅取得运行属性，秘密字段受控隐藏。

列表区分已保存原文、停用、已确认贡献与未确认状态。按正文身份复用有界解析，异步完成时核查身份；刷新与重新解析保留阅读对象，失效写入口及时关闭。

## 受限删除

删除仅作用专用正文直接定义，provider下载内容与引用保持各自生命周期。同名覆盖删除可能露出下层定义，确认明确这一后果。

删除已保存但应用失败时保留新正文／revision，重试仅应用该保存结果。结果待核实时关闭旧写入口；整体恢复后由新行重新捕获会话，旧回调持续撤销。

## 表单布局与校验

复杂协议、组和provider以完整章节组织，宽窗并排相关章节，长证书／表达式／集合按需跨区，窄窗保持明确顺序。同一Form、控制器、草稿、选区／composing及嵌套记录身份持续。内嵌子编辑只改父草稿，短规则、命名和单键值保持单列。

校验先覆盖完整草稿，按稳定字段／嵌套记录定位首错，展开章节并滚至实际错误项。折叠和离屏项均参与，集合保持惰性，内部预算取实际父空间、字号、键盘、安全区与保存区。

字段反馈、标题、阅读与保存区保留稳定空间，等待、错误、重试及失效维持锚点。标题和保存区按实际文字、字号及剩余高度预算；短高工作区使用单行标题和紧凑保存区，完整标题通过Tooltip和语义提供，失败详情保持可达。布局拆合保持同一保存控件和输入值，收起章节释放其内部输入焦点，展开首错后定位实际输入。保存执行字段与安全局部原文检查；实际YAML经Compose及公开parser单独验证，24种GUI与28种原始type分别验收，见[表单契约](../development/build-and-test.md#表单到parser契约)。
