# 运行控制与策略选择

总览的配置行进入配置管理，中央按钮启动／停止VPN接管，模式入口调整规则／全局／直连。策略页用于成员选择和HTTP延迟测试；局域网代理服务有独立设置入口，应用访问及Always-on位于设置的Android组。

VPN和局域网服务分别启停；开启意图、core context及实际TUN／监听状态分别显示。启动使用完整保存组合，运行中修改只替换本次操作涉及的输入。实现字段与替换范围见[数据与操作](../architecture/data-and-operations.md#保存选择与实际运行输入)。

## 启动和停止

1. 在“配置管理”点击要使用的配置卡，确认选中描边和名称字重；没有配置时先按[导入步骤](configurations.md#导入与新建)添加。
2. 回到总览，检查配置行，点击中央“启动接管”。系统打开VPN授权时完成确认。
3. 接管就绪后，运行计时开始，中央按钮变为“停止接管”。打开联网应用后，总览显示上下行活动。
4. 要关闭接管，点击“停止接管”，等待实际资源及所属旧进程退出。局域网服务仍开启时，应用用新进程继续提供该服务，现有连接会短暂断开；若已确认Always-on，按提示打开系统VPN设置处理系统接管。

启动过程中也可点击中央停止入口。停止操作等待原调用、资源及旧进程退出；退出确认后显示关闭。被取消的启动调用不覆盖停止结果，停止自身的释放失败或退出未确认仍通过 SnackBar 反馈。

| 操作中遇到的情况 | 处理入口 |
| --- | --- |
| 授权取消或失效 | 回总览重新启动，完成系统VPN授权 |
| 配置准备或启动失败 | 在 SnackBar 中打开错误详情，按字段／资源原因修改本地正文或更新远程来源，再启动 |
| 正文已保存但连接失败 | 保留已保存正文，处理错误后回总览启动；停止后再启动会加载完整保存组合 |
| 状态未知或释放未确认 | 查看 SnackBar 错误详情，等待原调用及释放结果，使用当前可用的停止／恢复入口 |

## 运行状态

总览中央按钮及下表描述VPN接管；局域网服务状态在其独立入口显示。LAN-only的core context已运行，不表示VPN已经接管。

| 状态 | 含义与可用行为 |
| --- | --- |
| 关闭 | 接管和必要资源已确认停止；保留已保存配置及预选 |
| 等待 | 操作已受理、结果未确认；系统VPN授权等待单独说明 |
| 运行 | 必要服务与接管组件已就绪；可停止及执行允许的运行调整 |
| 未知 | 当前状态无法核实；保留恢复入口，禁止冲突启动 |
| 异常阻断 | 接管尚未释放，部分操作因错误不可用；通过 SnackBar 查看原因及可用的停止或恢复操作 |

直连模式保持接管运行，关闭须确认必要资源退出。启动失败且清理完成显示关闭并附原因；清理未确认保持未知。

初始化、收到平台通知、恢复前台和命令完成后，应用自动读取运行状态。首次读取显示等待；失败时保留上次状态，已确认运行时仍可停止。读取成功后直接更新，不反复提示。平台返回未知状态与通信读取失败分别显示。

存在实际 RUNNING context 时，配置行显示当前加载项；没有时显示所选配置。保存正文、选择与运行版本不一致时，就近标出差异。LAN-only 的使用项不显示 VPN 接管标记；启动、停止和修改使用当前确认状态。

## 内核退出与恢复

内核异常退出后，当前页面继续打开，草稿、焦点、文字选择、搜索、滚动位置和详情保留。依赖旧内核的操作停止，已经完成的保存保留；编辑、保存和复制错误仍可使用。应用显示同一条稳定中断提示，不跳转到崩溃页或反复弹出相同错误。

在当前工作区的中断 SnackBar 点击“错误详情”，查看原因并按需要选择：

| 入口 | 操作及结果 |
| --- | --- |
| 重新启动 | 读取当前已保存的所选配置、启用插件与偏好，建立新内核；再次失败时保留错误并保持停止 |
| 更换配置 | 打开配置管理，保存新的选择，保持停止；返回总览后再点重新启动 |
| 清理文件 | 打开缓存数据库及Geo文件逐项清单，确认后等待旧进程退出再删除；仅清理后保持停止，选择清理后启动则使用最新完整保存组合 |

退出原因未确认时显示内核已退出及已有错误，不推测系统回收或崩溃原因。通信中断另显示状态未确认，仍需等待或重试，不能直接按已停止处理。部分文件清理失败会保留完成项、失败文件和重试入口，不删除其他用户文件，也不关闭当前页面。

## 局域网代理服务

该服务通过所选本地地址向其他设备提供HTTP和SOCKS5，可不启用VPN。VPN与局域网开关分别生效；完整重载或VPN切换时现有代理连接可能短暂断开，另一功能的开启意图保持，恢复结果另行显示。

1. 打开“设置 → 局域网代理服务”，选择当前可用的Wi-Fi、热点或USB网卡地址。可同时选择多个地址，不使用通配监听。
2. 设置端口及SOCKS5 UDP；默认在同一端口提供HTTP／SOCKS5 TCP及UDP，不要求认证。需要其他认证、TLS或监听选项时编辑该插件原文。
3. 保存并启用，等待实际监听状态。保存成功不等于监听已建立；失败时查看具体错误，处理端口占用或地址问题后重新启动。
4. 在另一台可达设备上，将应用显示的地址和端口填入HTTP或SOCKS5代理设置。IPv6地址复制时保留scope并使用正确的主机／端口格式；连接后检查目标访问结果。
5. 只停止局域网服务时使用该页开关；VPN仍开启则保持其意图。只停止VPN时，局域网服务按原设置继续运行。

已识别蜂窝、VPN和回环地址不可选。未知类型不自动启用，确认用途后可选，界面仍显示类型未知。地址或接口身份失效时关闭对应监听并显示中断；选择当前地址、保存后重新启动，不自动跟随新地址。应用不创建热点或配置USB网卡，需先由系统完成相应网络连接。

服务接受系统路由到所选本地地址的连接，不额外按物理入站网卡或来源IP过滤。用户在YAML中配置的认证、来源规则、协议和路由由mihomo执行。高级配置中的其他监听独立保留，不受本功能开关认领。保存、未知字段及备份见[局域网插件](configurations.md#局域网代理插件)。

## 总览

总览分为连接控制和网络活动两个区域：

| 布局条件 | 区域安排 |
| --- | --- |
| 两区可同时完整操作 | 左侧控制区、右侧网络活动；控制区按字号分配320至480逻辑像素宽度 |
| 窄窗或大字使两区不足 | 上下排列，网络活动区底边与底部导航相接 |
| 高度较小 | 缩小组间留白，滚动查看完整页面 |

宽窗的网络活动区右边与内容区相接，相接处使用直边；安全区在各区域内部处理，技术正文和网络数据限制最大宽度。标题、入口、上下行指标、连接与内存摘要根据剩余高度分配间距；上下行列距随宽度增加，但设有上限。同组标签、数值、曲线和累计值保持相对间距。

布局拆合复用控制器、滚动位置和控件状态；相同约束下等待、运行和错误保留构图，见[布局连续性](interaction.md#布局连续性)。

品牌与配置、启停与状态、模式分别形成操作组；充裕高度分配到组间，保持组内操作与说明的紧密关系。配置行进入配置管理，中央圆形按钮承担启停，状态、计时和模式按固定顺序显示。空配置提供导入入口；总览与设置复用模式浮板及同一重连偏好。

运行时品牌色覆盖总览页面背景，网络活动作为浮板沿所属明暗主题保持中性。亮色主题的启停主体采用品牌色与白色的角色互换：停止时浅色背景、品牌色实心圆和白色电源图形；运行时品牌色背景、白色实心圆和品牌色电源图形。暗色主题独立使用低亮度背景、协调的品牌色阶及清晰的实心按钮，控制大面积亮度和局部反差。空配置和禁用状态保持相应状态表达，通过真实禁用语义、状态和就近原因表达可操作性。文字根据所在区域的背景和文字层级选择前景，保持可读对比度。等待、快速反向及主题切换保持按钮尺寸、位置及文字可读，安全区按对应表面处理。

启动成功后中央按钮显示停止动作并开始运行计时；失败或部分完成通过所属工作区的 SnackBar 提示，点击后查看技术详情。状态未知时显示实际未确认状态。配置管理提供完整配置名称。

## 运行计时与动效

运行计时以原生接管状态进入RUNNING的时刻为起点，采用包含设备休眠时间的单调时钟。主行显示时、分、秒；累计时间达到一天后，副行显示累计天数。模式或策略的热切换沿用原有计时基线，重新建立VPN会话时重置该基线。界面仅更新发生变化的数字；恢复可见状态后，重新读取实际计时样本。

确认运行后，波纹从按钮边缘出现，约每2秒一圈，每圈约6秒扩散并淡出。停止请求开始后，不再增加新圈，已有圈继续外扩并约1.5秒淡出。快速重启时，旧圈继续结束，新圈从按钮边缘出现。动画不延迟业务状态更新。

StatusText使用约100ms退出、180ms进入的文字过渡；文字相同时不重播。过渡中收到新状态时，从当前文字、透明度和偏移继续。系统减少或停用动画、或Ticker停用时，直接显示目标文字。波纹按按钮的位置和尺寸局部绘制；不可见、被覆盖或减少动效时停止装饰动画，窗口可见但失焦时按[可见性规则](interaction.md#可见性与交互)处理。

## 运行模式

模式为规则、全局和直连。普通启动、切换配置及Always-on优先采用合成正文显式设置的mode；没有该字段时，使用已保存的模式，两者均无时采用内核默认值，应用不额外写入rule。无RUNNING context时，选择模式保存供以后使用；已有PREVIEW时按预览规则更新，不启动VPN或局域网服务。存在RUNNING context时，选择会更新当前模式，并保存为以后正文缺少mode时采用的值。用户YAML保持原文。

存在RUNNING context时，总览和模式浮板显示读回的实际模式，包括VPN已关闭、仅局域网服务运行的情况；无RUNNING context时显示回退或未预选。身份完整且状态正常的RUNNING context尚无实际模式及读取错误时，显示“未确认”并继续前台刷新，不把启动、恢复或结果发布期间的缺值当作读取失败，也不以保存的回退值代替实际模式。模式读取失败独立反馈，VPN状态与停止入口保持可用。保存成功后应用，应用待确认时保留保存值及实际结果；仅局域网运行时同样等实际模式读回后关闭浮板。

模式与策略共用“切换后重新连接”，默认关闭。关闭时使用公开接口热切换，已有连接继续运行；开启时，选择实际变化后先保存，再结束旧core process并用新进程装载，仅替换本次模式或成员选择，保留VPN／局域网开启意图。选择相同值时保持当前运行；无RUNNING context时只保存，已有PREVIEW按预览规则处理。

模式浮板用规则蓝、全局紫、直连青绿辅助识别，文字和大面积表面中性；选择状态由控件样式表达。成功读回后关闭，失败时保留浮板并通过 SnackBar 查看原因。长文、键盘和安全区沿通用浮层适配。

## 策略浏览与选择

停止时可按需准备预览，查看策略组及预选；总览和设置只读取自身所需状态。预览沿[context lifecycle](../architecture/core-integration.md#context-and-preview)跨正常切页复用。

| 组类型 | 用户操作 |
| --- | --- |
| select | 手动选择成员 |
| url-test／fallback | 固定成员或恢复自动 |
| load-balance | 只读查看；没有唯一当前成员 |

每个配置保存策略组类型，以及固定成员或自动选择的偏好；自动组当前选择的now从内核读取。保存后重新读取当前选择，浮窗关闭后已受理操作仍继续返回结果。成员或组类型变化导致偏好无法恢复时，保留偏好并列出未恢复项；该组使用当前默认或自动选择，默认成员可能是DIRECT。

主策略页按组名进行不区分大小写的字面搜索，并同时应用hidden开关与GLOBAL显示条件；原始输入和输入法组合状态保持不变。hidden开关只在本次UI会话内保存。GLOBAL在全局模式下显示、直连模式下隐藏，规则模式下被引用时显示。要查看完整定义属性，从设置打开“全部策略组”。

策略使用按需构建的紧凑网格，突出组名和当前成员，组类型使用次要文字。组名最多显示两行，列数按窗口与字号计算。自动读取或顺序变化时，保留仍存在的可见组及屏幕位置。来源变化后保留最后内容并注明旧结果；读取失败通过 SnackBar 查看实际错误，成功后结束本轮失败提示。

组图标通过HTTP／HTTPS下载，位图由SDK解码，SVG交`vector_graphics_compiler`解析；卡片、浮窗和连接详情共用图标来源与按组类型区分的默认图标。位图最多1MiB、SVG最多256KiB，加载期限8秒，HTTP客户端使用应用的信任证书。下载、解析或显示失败时，在原位置显示默认图标，并通过图标提示提供错误。

## 成员浮窗与延迟测试

点击策略组卡片，从原卡片位置展开成员浮窗，同时只打开一个。父卡片、网格位置和阅读位置保持不变。浮窗中的成员组可选择，或查看直接摘要；要调整其他组，先回主网格打开对应卡片。返回、关闭和点击窗外均关闭浮窗，成员选择成功后留在浮窗。

成员按单列显示，名称与摘要分层；选中成员使用背景和 `w700` 名称，未选中使用 `w400`，名称与 emoji 保持原字符串。自动组有固定成员时显示“固定：成员”和靠结束端对齐的“恢复自动”；没有固定成员时不显示该行。长列表在浮窗内滚动，关闭按钮始终可访问。首次内容决定浮窗高度上限，后续增加的内容在内部滚动；窗口与字号变化时重新适配。等待、成功、失败或来源失效时保持浮窗位置。来源被替换后，保留原组最后内容并改为只读，同名新组不替换该浮窗；同一来源暂时读取失败，恢复后可继续操作。

整组和逐成员 HTTP 测试使用当前依赖公开 DefaultTestURL，单项5秒、最多4并发、批次120秒。进行中显示进度，成功显示真实延迟；失败和超时在批次结束后汇总到 SnackBar，详情保留成员、时间和实际原因。结果原位更新并保留成员顺序，选择沿独立用户动作处理。

延迟表示至HTTP目标的调用结果；URLTest更新alive／history并可能影响自动组健康选择。调用错误、expected-status及底层退出各有语义，见[策略接口](../architecture/core-integration.md#strategy-api)。卡片取当前成员有效延迟或真实内置Reject，load-balance按多成员状态展示。

策略读取状态如下：

| 状态 | 展示及下一动作 |
| --- | --- |
| 首次／尚未加载 | 显示准备状态及原位加载入口，防重复提交 |
| 已加载且可见 | 每5秒读取一次 |
| 暂时读取失败 | 保留原内容及完整错误，按1／2／5／10／30秒退避 |
| 来源变化或准备失败 | 保留旧snapshot并注明来源已变化，禁用修改；准备错误提供查看和重试入口 |
| 隐藏 | 暂停新的界面读取，已受理调用继续返回结果 |

每次策略读取都等前一个 Future 返回后再开始。取消、界面等待超时或进入后台后，仍保留原调用返回的数据或错误；替换前可继续阅读已加载的业务内容，下一次读取成功后清除读取错误。

## 网络活动

网络活动显示mihomo全局转发的上下行流量，包含直连。速度以同一内核来源的累计差和单调时钟间隔计算，上下行分别检查。首次采样、数据缺失、累计倒退或间隔超过5秒时，显示无有效速度。

业务Engine保留30秒趋势和本次core context累计，统计VPN及局域网入口的实际转发，页面隐藏后继续采样。新进程、停止或来源标识变化时重建趋势与累计基线；热切换、进入后台和UI重建保留同源基线。大小及数量限制见[连接与流量](../architecture/core-integration.md#connections-and-traffic-api)。

网络活动在同一连续区域显示，下载／上传依次显示标签、速度、曲线和累计，采用青绿实线／钴蓝虚线。各图独立缩放，真实30秒窗口固定最新点在右端；曲线、端点与尺度共用过渡，通常一个采样周期、延迟时最长1秒追上。数值及时显示，没有有效样本的时间段不连线；首样本、恢复、新会话、尺寸变化及减少动效直接定位。

速度按1024倍使用B/s、KiB/s、MiB/s、GiB/s，约3位有效数字，到1024升档、低于0.9降档。零为0 B/s，未知／过期为“—”，数值和单位紧邻，长值保持可读。

曲线下显示连接数与进程内存。连接为排除Inner的实际活跃观察数。第一行显示“应用内存 X MB”，与连接数的文字基线对齐，不另设“内存”标题。内核进程存在时，在下一行显示“内核内存 Y MB”，预览进程也显示。预留第二行高度，内核启停和采样失败不改变摘要的位置。

两项内存分别读取，不加总；失败项显示“—”，失败原因保持可达。查看数值不启动内核。空间不足或字号放大时，连接数与整块内存上下排列，不缩小字号。

上下行和“最近连接”进入同一连接任务。端点小波纹表示正在观察，零流量也可播放；不可见、覆盖、停止、未知、过期及减少动效时停动，读取失败归所属稳定反馈位置。

## 应用访问

所有应用、仅选中、排除选中三种互斥策略，默认所有应用。按真实名称／包名搜索，可显示系统应用；共享UID联动并说明，已卸载包保留选择身份并标缺失，可主动取消。

应用访问修改需要点击保存，界面分别显示保存结果和当前接管范围；配置显式名单的优先级就近说明。仅选中要求有效选择，启动再次检查；运行时保存后只应用本次访问设置并正常重连。数据恢复或替换后保留原草稿与选择，禁用该页编辑与保存，提示重新打开；重连确认返回时再次核对原草稿身份。其他应用沿系统网络和其独立lockdown条件处理。

宽窗中，应用访问设置的控制区域与应用名单分别排列，长应用名在名单内完整阅读；窄窗或高度较小时重新布局。图标、选择、数量和阅读位置保持稳定，异步图标按包名核对后显示。Builder与UID处理见[Android应用访问](../architecture/android.md#应用访问)。

## Always-on

在“设置 → Android → Always-on”查看系统状态，或打开Android VPN设置。返回应用前台后重新读取；系统版本较低或没有可读服务实例时显示未知。已确认Always-on时，普通停止先说明系统接管状态，并引导到系统设置。

Always-on和lockdown在Android VPN设置中配置。正常系统启动由同一AppRuntime读取最新完整保存组合，缺配置或有效allow为空等错误就近显示。内核异常后暂停进一步装载，系统重复创建Service只更新状态和恢复通知；打开应用处理错误，再明确重新启动。应用不改变系统常开或阻断设置。用户命令、Worker和备份恢复各自携带来源与授权进入同一执行链。

## Android系统入口

长按快捷菜单在API25+提供固定连接／断开；API24+提供快捷设置磁贴和桌面小组件。磁贴由系统快捷设置编辑界面添加，小组件由Launcher选择器添加，应用设置保留对应功能入口。

系统入口分别发送固定start或stop动作，使用与应用内相同的业务执行流程。已处于目标状态时直接返回对应结果。缺少VPN授权时打开系统授权界面，取消后保持停止；没有配置或操作失败时提供打开应用的入口。锁屏时先按系统要求解锁。点击主体打开总览，并检查未保存修改。磁贴和小组件显示最近确认状态，进程终止后保留该状态。

## 桌面小组件

小组件采用一种方形构图，完整内容边长至少144dp；Launcher按实际格数分配，宿主以较短边居中。低于144dp时显示容量提示，仅提供安全打开应用动作。

| 元素 | 几何与表达 |
| --- | --- |
| Logo | 左上48dp独立圆形 |
| 启停 | 右上56×48dp目标；轨道52×32dp、滑块26dp，与Logo同中心线 |
| 主状态／模式 | 下方左对齐并紧邻，16／14sp；运行显示实际模式，停止显示已保存模式 |
| 内容内收 | 普通字号16dp，大字号12dp；144dp覆盖1／1.3／2x |

小组件内容整体垂直居中。点击主体打开总览，启停使用紧凑胶囊按钮，触控区域至少48dp。主状态、模式、Logo和按钮各占固定区域，未知、忙碌或失败以对应文字和控件状态表示。品牌及系统控件见[Android系统入口](../architecture/android.md#系统入口)。
