# 运行控制与策略选择

运行操作围绕当前完整配置、实际接管状态和用户本次明确意图展开。本规范同时定义总览、模式与策略界面，以及应用访问和Android系统入口；保存与实际输入的实现见[数据与操作契约](../architecture/data-and-operations.md#保存选择与实际运行输入)。

## 运行状态

| 状态 | 含义与可用行为 |
| --- | --- |
| 关闭 | 接管和必要资源已确认停止；保留已保存配置及预选 |
| 等待 | 操作已受理、结果未确认；系统VPN授权等待单独说明 |
| 运行 | 必要服务与接管组件已就绪；可停止及执行允许的运行调整 |
| 未知 | 当前状态无法核实；保留恢复入口，禁止冲突启动 |
| 异常阻断 | 接管仍持有且符合明确阻断条件；按真实条件表达 |

直连模式保持接管运行，关闭须确认必要资源退出。启动失败且清理完成显示关闭并附原因；清理未确认保持未知。

初始化、平台通知、前台恢复和命令完成后自动读取。首次读取明确等待，失败保留原投影；已有明确运行状态时仍可停止。健康同步静默更新，平台返回未知与通信失败分别表达。

运行时配置行优先显示实际加载项，停止时显示选择；保存、选择与实际运行有差异时就近说明。原数据可供标明过期的阅读，启停及修改按当前确认身份受理。

## 总览

总览承载连接控制与网络观察。宽窗在两个区域均能完整操作时，采用左侧紧凑控制区与右侧网络活动表面，工作区填满实际内容区；控制区随字号在320至480逻辑像素之间分配宽度。窄窗网络表面底边与底部导航连续，宽窗右边与实际内容区右边界相接，相接边采用直边。安全区在所属表面内部处理，网络阅读内容独立保持有界宽度。标题与入口、上下行指标、连接与内存摘要按所属区域的实际剩余高度分配组间留白；上下行列距随可用宽度有界增加。窄窗和大字号下按实际正文预算恢复上下布局，内容沿实际可见高度展开；短高时收敛组间留白并沿页面滚动访问完整内容。两轴独立适配，同组标签、数值、曲线和累计之间的距离保持稳定。两种布局复用同一控制器、滚动位置和控件状态；相同约束下，各运行状态保持构图，遵守[布局连续性](interaction.md#布局连续性)。

品牌与配置、启停与状态、模式分别形成操作组；充裕高度分配到组间，保持组内操作与说明的紧密关系。配置行进入配置管理，中央圆形按钮承担启停，状态、计时及模式保留稳定层级。空配置提供导入入口；总览与设置复用模式浮板及同一重连偏好。

运行时品牌色覆盖总览页面背景，网络活动作为浮板沿所属明暗主题保持中性。亮色主题的启停主体采用品牌色与白色的角色互换：停止时浅色背景、品牌色实心圆和白色电源图形；运行时品牌色背景、白色实心圆和品牌色电源图形。暗色主题独立使用低亮度背景、协调的品牌色阶及清晰的实心按钮，控制大面积亮度和局部反差。空配置和禁用状态保持相应状态表达，通过真实禁用语义、状态和就近原因表达可操作性。文字根据实际承载表面和层级选择前景，保持可读对比度。等待、快速反向及主题切换保留几何与可读性，安全区按对应表面处理。

普通成功由中央状态和按钮表达，失败、部分完成及未知原因沿状态入口或通用反馈呈现。状态详情触控至少48逻辑像素，原因撤销时动作同步退出；配置管理可取得完整名称。

## 运行计时与动效

运行计时以原生接管状态进入RUNNING的时刻为起点，采用包含设备休眠时间的单调时钟。主行显示时、分、秒；累计时间达到一天后，副行显示累计天数。模式或策略的热切换沿用原有计时基线，重新建立VPN会话时重置该基线。界面仅更新发生变化的数字；恢复可见状态后，重新读取实际计时样本。

确认运行后波纹从按钮边缘加入，约每2秒一圈、每圈约6秒扩散淡出。停止请求开始后仅保留已有圈外扩，并约1.5秒淡出；快速重启延续旧圈收尾，新圈从源点加入。业务操作按真实状态及时结算。

文字状态采用短退出／进入，参考100ms／180ms，同值保留现有呈现。波纹与按钮共用几何并局部绘制；不可见、覆盖或减少动效时停装饰，可见失焦沿[可见性规则](interaction.md#可见性与交互)处理。

## 运行模式

模式为规则、全局、直连。普通启动、切配置及Always-on按合成显式mode→保存可空回退→rule取值；停止时预选只保存，运行时选择同时更新当前模式与以后回退，用户YAML保持原文。

运行时显示读回的实际模式，停止时显示回退或未预选。模式读取失败独立反馈，VPN状态与停止入口保持可用。保存成功后应用，应用待确认时保留保存值及实际结果。

模式与策略共用“切换后重新连接”，默认关闭：公开接口热切换，已有连接继续按实际映射存续；开启时，真实选择变化先保存，再正常停止并重建实际输入，只替本次模式／成员意图。相同值保留当前运行，停止时只保存。

模式浮板用规则蓝、全局紫、直连青绿辅助识别，文字和大面积表面中性；选中、勾号和进度保留稳定槽位。成功读回后关闭，失败保留浮板及具体原因。长文、键盘和安全区沿通用浮层适配。

## 策略浏览与选择

停止时可按需准备预览，查看策略组及预选；总览和设置只读取自身所需状态。预览沿[上下文生命周期](../architecture/core-integration.md#上下文与预览)跨正常切页复用。

| 组类型 | 用户操作 |
| --- | --- |
| select | 手动选择成员 |
| url-test／fallback | 固定成员或恢复自动 |
| load-balance | 只读查看；没有唯一当前成员 |

每配置保存组类型和固定／自动意图，临时now属于自动健康选择。保存后读回实际选择；关闭浮窗后已受理操作继续结算。失效偏好保留记录并说明未恢复，组按实际默认或自动规则继续，默认可能为DIRECT。

主策略页按父组名进行大小写不敏感的字面搜索，叠加hidden／GLOBAL条件并保留原始输入与composing。hidden开关属当前UI会话；GLOBAL按全局显示、直连隐藏、规则模式被引用时显示。全部策略组的定义属性由设置入口完整呈现。

策略采用紧凑惰性网格，突出组名与当前成员，类型弱化，固定意图用小标记。组名保留有界两行，图标、状态与来源有稳定槽位；真实窗口和字号决定列数。结构刷新与重排保持存活组和阅读位置。

组图标采用HTTP／HTTPS的PNG、JPEG、WebP及静态SVG，卡片、浮窗、连接详情共用来源与类型回退。位图1MiB、SVG256KiB，总期限8秒、至多3次重定向；HTTPS重定向保持HTTPS，请求隔离主配置凭据并移除Cookie／Authorization。失败显示槽内回退；SVG按静态能力加载，脚本及外部资源由准入检查拒绝。

## 成员浮窗与延迟测试

从父卡片原位连续展开唯一单层成员浮窗，保留来源关联、网格占位和阅读位置。成员组只可选择或查看直接摘要；调整其他组回主网格打开。返回、关闭或点窗外沿同一关闭路径；选择成功留在浮窗。

成员行单列紧凑，名称和摘要分层，长列表内部滚动，关闭持续可达。首次自然内容确定有界高度，后续变化内部滚动；窗口和字号变化重新适配。等待、结果、失败及来源失效保留浮窗锚点。来源失效保留最后内容并只读，同名替换时旧窗继续使用原有失效身份；同一身份暂时读取失败恢复后可继续。

整组和逐成员HTTP测试使用当前依赖公开DefaultTestURL，单项5秒、最多4并发、批次120秒。未测、等待、成功、失败、超时和取消分别表达；结果原位更新并保留成员顺序，选择沿独立用户动作处理。

延迟表示至HTTP目标的调用结果；URLTest更新alive／history并可能影响自动组健康选择。调用错误、expected-status及底层退出各有语义，见[策略接口](../architecture/core-integration.md#策略接口)。卡片取当前成员有效延迟或真实内置Reject，load-balance按多成员状态展示。

可见策略页及成员浮窗正常每5秒读取一次，失败按1／2／5／10／30秒退避；真正隐藏时暂停对应UI读取，失焦按通用可见性规则处理。准备失败提供明确重试，旧数据上的修改禁用。首次加载、未加载、真实空集合和错误分开，加载入口保持原位并防重复，同一原因只在所属位置表达。

## 网络活动

网络活动显示mihomo全局转发上下行（含直连），速度由同身份累计差及真实单调间隔计算，两方向独立校验；首样本、缺失、倒退或间隔超过5秒时显示无有效速度。

逻辑引擎保留30秒趋势和本次VPN累计，页面隐藏时业务采样继续。新会话、停止或core身份改变清趋势；累计在接管开放前捕获基线，热切换、后台及UI重建保留，完整重连重建。预算见[连接与流量](../architecture/core-integration.md#连接与流量接口)。

网络活动为连续内容面，下载／上传依次显示标签、速度、曲线和累计，采用青绿实线／钴蓝虚线。各图独立缩放，真实30秒窗口固定最新点在右端；曲线、端点与尺度共用过渡，通常一个采样周期、延迟时最长1秒追上。数值及时显示，缺口断开；首样本、恢复、新会话、尺寸变化及减少动效直接定位。

速度按1024倍使用B/s、KiB/s、MiB/s、GiB/s，约3位有效数字，到1024升档、低于0.9降档。零为0 B/s，未知／过期为“—”，数值和单位紧邻，长值保持可读。

曲线下并列连接／内存摘要，连接为排除Inner的实际活跃观察数；内存为整个进程RSS（含共享页），停止也可独立读取，标签为“内存”。两项按稳定槽位排列，窄窗大字按静态约束纵排，失败原因保持可达。

上下行和“最近连接”进入同一连接任务。端点小波纹表示正在观察，零流量也可播放；不可见、覆盖、停止、未知、过期及减少动效时停动，读取失败归所属稳定反馈位置。

## 应用访问

所有应用、仅选中、排除选中三种互斥策略，默认所有应用。按真实名称／包名搜索，可显示系统应用；共享UID联动并说明，已卸载包保留选择身份并标缺失，可主动取消。

应用访问草稿显式保存，保存偏好与实际接管分别显示；配置显式名单的优先级就近说明。仅选中要求有效选择，启动再次检查；运行时保存后只应用本次访问设置并正常重连。数据恢复或替换后保留原草稿与选择，关闭其编辑和保存入口并提示重新打开；重连确认返回时再次核对原草稿身份。其他应用沿系统网络和其独立lockdown条件处理。

应用访问宽窗由持续控制区与长名称单区组成，窄／短窗重排；图标、选择、数量与阅读锚点稳定，迟到图标按包身份核验。Builder和UID规则见[Android应用访问](../architecture/android.md#应用访问)。

## Always-on

提供真实可读状态与打开官方VPN设置，前台恢复重读。低版本或不可读取时为未知。已确认Always-on时普通停止先说明系统接管状态并引导系统设置。

Always-on和lockdown由系统控制，系统启动读取最新完整保存组合，缺配置、坏组合或有效allow为空时如实失败。普通命令、Worker与备份恢复沿各自来源及授权处理。

## Android系统入口

长按快捷菜单在API25+提供固定连接／断开；API24+提供快捷设置磁贴和桌面小组件。磁贴由系统快捷设置编辑界面添加，小组件由Launcher选择器添加，应用设置保留对应功能入口。

入口按明确start／stop动作复用同一业务链，已有期望状态按幂等方式结算，start和stop始终使用各自固定动作。缺VPN授权进入可见系统授权，取消后保持停止；缺配置或失败提供打开应用的恢复路径，锁屏沿系统解锁。主体打开总览并遵守未保存编辑保护。系统投影是最近确认状态，进程终止后保留最后一次确认的投影。

## 桌面小组件

小组件采用一种方形构图，完整内容边长至少144dp；Launcher按实际格数分配，宿主以较短边居中。低于144dp时显示容量提示，仅提供安全打开应用动作。

| 元素 | 几何与表达 |
| --- | --- |
| Logo | 左上48dp独立圆形 |
| 启停 | 右上56×48dp目标；轨道52×32dp、滑块26dp，与Logo同中心线 |
| 主状态／模式 | 下方左对齐并紧邻，16／14sp；运行显示实际模式，停止显示已保存模式 |
| 内容内收 | 普通字号16dp，大字号12dp；144dp覆盖1／1.3／2x |

内容自然聚合并整体垂直居中，主体打开总览，启停采用局部紧凑胶囊与至少48dp目标。主状态、模式、Logo和动作保持固定槽，未知、忙或失败以实际语义表达。品牌和投影见[Android系统入口](../architecture/android.md#系统入口)。
