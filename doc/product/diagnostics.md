# 诊断、内核查看与资源

诊断展示当前真实内核与来源，运行时绑定实际身份，停止时按需准备预览；设置首页和最近日志按自身所需数据读取。准备、读取和业务更新分别反馈。

## 查看范围与共同交互

节点、全部策略组、规则、资源、运行配置和日志各有明确任务入口。查询区分等待、真实空集合、筛选无结果、失败与过期，数量未知为“—”，页脚标单位和实际范围。相同原因只在所属状态位置表达一次，完整原因可读。

分类同时管理[直接本地定义](local-definitions.md)，预览与运行投影撤销后本地原文仍可管理。搜索保留原始输入和composing，按来源及路径区分对象；远程／内置属性缺原文时明确显示运行属性。

集合与属性按实际空间并排或逐页，初始保留无选择状态，详情由用户选择触发。两区共用所属控制器，窗口拆合保持输入、所选对象及两区阅读位置；集合输入开始后，窄窗保持集合区域，完成输入后仍可继续浏览，工具栏的详情按钮重开缓存选择。Ctrl／Cmd+F进入同一集合搜索；Escape按当前详情、输入和页面的顺序退出。筛选或分页排除所选项目时保留详情并说明其与当前列表的关系，来源替换后保留可复制快照并撤销旧动作。技术阅读宽度按局部任务预算，长内容惰性呈现；刷新、分页、解析与重排遵守[集合规范](interaction.md#集合与详情)。

阅读面绑定打开时的来源身份，更新／换源／文件变化撤销原分页和写入口。暂时失败与来源撤销分开，同名对象建立新上下文；读取保留真实在途槽与最新意图。

## 节点与规则

代理节点包含主配置和全部proxy-provider成员，以名称／来源／类型搜索，同名或空名provider按精确来源区分。built-in独立说明，能力与延迟采用实际返回值。

全部策略组列出hidden／GLOBAL及实际属性，属性阅读和本地编辑遵循[定义规范](local-definitions.md#来源与可写性)。日常成员选择、自动意图和延迟测试由[策略任务](runtime-and-strategies.md#策略浏览与选择)统一管理。

规则按实际顺序，sub-rules按名称分组；RULE-SET进入对应规则集，可识别Geo引用进入资源。新增、修改、删除作用于直接本地定义，复合条件保持原引用语义。

## 规则集内容

domain／ipcidr显示公开接口的规范化运行集合，数量随合并去重变化；classical标识inline、缓存或声明来源。内容读取采用已取得的运行对象与来源路径，缺失字段明确说明。

分页约束UI展示，原生完整集合读取的峰值单独测量。来源／缓存变化撤销原页，内容范围保持明确；接口见[内核资源](../architecture/core-integration.md#规则provider与geo)。

## 外部资源

按合成声明顺序列两类provider和Geo，区分已配置、本地存在、实际加载。HTTP执行更新，file重新加载／监视，inline无外部下载；状态如实说明。提供两类provider的[本地定义入口](local-definitions.md#策略组与provider)。

GeoIP、MMDB、GeoSite和ASN分别提供状态查看与单项更新，涵盖缺失或未启用资源。随包数据仅在文件缺失且对应geox-url子键缺省时补入；已有文件、替代名称与后续更新保留，损坏库交正常加载处理。

Geo自动目标沿内核公开范围，包含本进程记录的目标；各目标独立检查缺失、损坏与到期。缺损MMDB／ASN补齐可专用DIRECT，完成后的正常更新回当前路由。补齐与启用、自动更新开关分别处理。

provider刷新由内核配置驱动，Geo使用会话调度；两者在VPN／预览存续期运行，资源页按需观察，真实取消与退出由接入层结算。

资源分别显示数量、最近尝试、成功检查、真正替换和内核更新时间。mtime表示文件修改时间，缺依据时为未知；部分成功保留各目标结果及恢复入口。材料见[依赖依据](../legal/dependencies.md#公共数据资产)。

## 运行时配置

运行配置显示公开GetGeneral接口的实时只读JSON子集，提供格式化、字面搜索、刷新及脱敏。完整合成YAML与平台接管状态由各自接口取得，技术长文保留连续阅读和选择。

## 日志

日志来自内核真实订阅，支持级别过滤、字面搜索、清空和回到最新。显示过滤作用于客户端，内核默认级别为info。窗口最多1000条／1MiB，单条最多8KiB；字段脱敏先于缓冲，截短和丢弃明确标记。

跟随时阅读最新，退出跟随后淘汰保存活阅读行；清空仅作用客户端内存。日志采用单个有界会话窗口和best-effort脱敏，阅读时保留凭据风险意识。订阅与排空机制见[日志与信任材料](../architecture/core-integration.md#日志与信任材料)。

## DNS查询

DNS工具显式查询当前内核解析器，默认A，支持A／AAAA／CNAME／MX／TXT／NS／SOA／PTR／SRV／HTTPS／SVCB／CAA。PTR接受IP及合法owner，URL、路径、端口、控制符、编码或容量问题关联字段反馈，输入保留composing。

查询调用当前DefaultResolver，可能命中缓存；TUN的hosts／fake-IP链按网络集成另测。DNS关闭时反馈不可用，运行绑定完整身份，停止时按需预览。

| 限制 | 口径 |
| --- | --- |
| 原始名称 | 最多1024 UTF-8字节 |
| 请求JSON | 最多4KiB |
| 规范化名称 | label最多63字节，wire name最多255字节 |
| 调用／桥等待 | 5秒／6秒，一个真实在途查询 |
| 完整结果 | 至多512 RR、编码256KiB；超限整体失败 |

普通Unicode标签经IDNA，presentation转义交DNS库；规范化、wire校验和取消见[DNS接口](../architecture/core-integration.md#dns与缓存)。

结果显示Question、RCODE、本次调用耗时及Answer／Authority／Additional，每项保留name、type、class、TTL和可复制RDATA。NXDOMAIN与空Answer作为有效结果阅读，耗时对应本次调用。

### 查询与结果流程

设置打开紧凑查询对话框，名称、类型、查询按钮及独立清理菜单保持稳定；等待、字段校验和错误原位反馈。

成功自动进入有界结果面，窄窗可整页、宽窗可对话框；返回修改保留名称与类型。查询、等待、结果与返回共用工具生命期，内部切换延续任务及结果。

明确关闭工具时撤销UI身份并取消所属请求，后台及网络／配置／存储变化沿捕获身份处理，保留输入供继续。失焦仅延后结果呈现，真实查询槽保留至退出，长RR内部阅读，各状态保留操作与阅读锚点。

## DNS与fake-IP清理

| 动作 | 确认、结果与边界 |
| --- | --- |
| 清理DNS解析缓存 | 直接执行，原位等待、防重复；完成表示对应当前缓存清理调用返回，在途查询可立即回填；清理范围限定为所捕获的当前DNS解析缓存 |
| 清理fake-IP映射 | 一次确认旧地址可能失效、客户端可能需重新解析；覆盖当前IPv4／IPv6及启用时持久池，保留数据库文件；有效池缺失时说明当前为空，两族部分失败如实表达 |

DNS缓存与fake-IP映射采用两个独立动作。fake-IP结果保留IPv4／IPv6的存在性与已清理、未启用、未确认状态，以及持久池启用事实；汇总与逐族结果保持一致，混合完成状态保留各自事实。结果详情可重新打开并复制；失败时保留已发生影响和未确认范围。池存在性及并发边界见[公开能力](../architecture/core-integration.md#公开能力边界)。
