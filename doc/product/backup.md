# 备份、覆盖恢复与系统备份

主动文件备份用于迁移或恢复保存的配置、插件和偏好。VPN会话及系统授权采用各自实际状态。设置提供“导入设置／导出设置”两个直接动作。

## 备份范围

备份为未加密单文件，包含完整配置与插件正文、来源及可能的凭据、保存顺序、当前选择、ID／revision、角色、Loon选项、周期设置、每配置策略偏好、客户端模式、外观／语言／主色及Android应用访问偏好。

外部引用文件、Geo／provider缓存、日志、运行输入、系统授权、WorkManager数据库与Tailscale身份保持独立生命周期。导出时说明包含的敏感内容，用户选择可信保存位置。

归档固定包含manifest与三份业务数据。输入损坏、缺项、额外项、不支持版本或超限整体拒绝。保存的无效YAML也可备份；归档检查负责完整性，内核加载负责可运行性，计量见[归档准入](../architecture/data-and-operations.md#归档格式与准入)。

## 导出与覆盖流程

导出从一次一致读生成私有候选，提示敏感内容，由用户通过系统文件界面选一次性保存位置。外部写入和关闭均成功才报完成；取消与失败分别反馈，失败可能留下不完整外部文件。外部发布语义由系统提供者决定，用户原件保留。

导入一次选择后完整复制并验证私有候选，覆盖确认展示数量、选择、敏感内容与后果；长内容内部滚动，确认后提交同一不可变候选。

恢复采用整体覆盖，空集合明确清空相应旧项；缺必需部分或验证失败保留旧数据，旧库损坏时恢复入口仍可用。hash／CRC提供完整性，敏感风险由明确提示及用户保管处理。

## 结果与运行意图

验证及确认期间保持原连接。最终受理时正常停止原VPN与预览并确认资源释放；STARTING／STOPPING及释放待确认时拒绝冲突，保留可用候选。原停止状态保持停止。

三库提交后，原运行且当前用户意图仍要求运行时，按恢复后的完整组合尝试连接；失败保留恢复数据并明确“已恢复，连接未建立”。停止、写入与连接分别结算。

| 发生阶段 | 必须保留的事实 |
| --- | --- |
| 验证或确认前取消／失败 | 原数据和连接保持 |
| 正常停止后、提交前失败 | 数据可能未变，但连接已停 |
| 提交成功后连接失败 | 数据已恢复，运行未建立 |
| 提交后调度或附属刷新失败 | 保留恢复数据，分别说明附属结果 |
| UI等待结束而实际I/O在途 | 结果未确认，执行门与候选仍由实际执行保护 |

停止、写入、连接及调度各自反馈。取消保留已提交事实，事务与中断恢复见[三库恢复](../architecture/data-and-operations.md#三库恢复事务)。

## 界面与生命周期

两个设置动作在选择、准备、确认、提交与错误阶段保持原位。真实执行时表现进度，阅读确认／错误时停装饰并保留本次身份。风险、数量与覆盖范围随操作出现，语言变化保持入口锚点。

系统SAF临时后台与主动离开任务分别判断。返回结果早于resumed时保留候选和真实结果，等可交互再继续；主动切任务／离开页面撤销原UI身份。选择／准备阶段取消或超时后，迟到结果不能成为新恢复提交；已经提交的操作等真实执行结束后读取结果。

恢复期间保留旧完整展示或稳定等待态，并关闭修改入口。完成后旧表单、编辑器、菜单及回调持续失效；草稿保留复制用途。文件位置通过系统一次性选择，存储授权范围按该URI确定。

## Android系统备份

系统备份／迁移与主动恢复分属不同通道，正式三库中有恢复价值的数据按保护规则参与备份；缓存、事务、调度数据库、owner和运行会话保留各自生命周期。

API24–27排除敏感配置，API28+按系统加密条件允许：Android9–11使用相应规则，Android12+云备份要求客户端加密能力。执行受账户、配额、设备和系统实现影响，系统恢复逐文件处理，可能部分完成；主动SAF恢复另用三库事务。

系统恢复后读取偏好、校准调度并查询实际状态。VPN启动仍需要明确用户请求或系统独立发起的[Always-on](runtime-and-strategies.md#always-on)。平台机制见[归档接入](../architecture/android.md#归档与文件门)。
