# 配置、插件与正文编辑

“设置 → 配置与数据”中，“配置管理”保存和选择完整 mihomo 文档，“插件（复写）”管理对全部配置生效的有序 YAML 片段。VPN及局域网均未运行时，选择配置供下次启动；VPN或局域网正在运行时，切换配置会保存选择，并按原VPN／局域网开启意图重新装载。运行标记见[运行状态](runtime-and-strategies.md#运行状态)，记录格式及文件写入见[数据与操作](../architecture/data-and-operations.md)。

## 对象与来源

远程配置保存来源地址和下载正文，本地配置由应用保存正文，两者按保存顺序排列。远程正文只读，更新成功后替换；本地正文可以编辑。下载支持 HTTP／HTTPS，执行正常 TLS 证书校验，重定向时隔离来源凭据。

插件也区分本地和远程，供全部配置共用。本地插件及[本地自定义插件](local-definitions.md#保存位置与入口)可全文编辑；草稿和撤销历史保存在编辑页内存，点击保存后写入文件。远程插件从来源下载新正文。

名称去掉首尾空白后须非空，最多 80 UTF-8 字节，界面用 B 显示计数；超限时保留输入并禁用提交。远程导入不填名称时使用来源主机名，文件导入使用去掉扩展名的文件名。自动名称超限时，在完整 Unicode 码点处截取可容纳的前缀。正文中的节点、组和 provider 名称由内核检查。

## 导入与新建

点击配置管理的添加按钮，菜单提供“从 URL 导入”“从文件导入”“新建本地配置”。

| 操作 | 步骤与结果 |
| --- | --- |
| URL 导入 | 输入地址和可选名称，点“下载并保存”；下载、解码成功后新增记录。尚未选择配置时选中它，否则保留原选择 |
| 文件导入 | 在系统文件界面选择一个文件，应用读取完整正文，成功后返回列表 |
| 本地新建 | 输入名称、继续，在正文页编辑直连模板并保存；第一次成功保存时才创建记录，未修改模板也可保存 |

配置导入使用完整 mihomo 文档。保存允许空白或无效 YAML，准备或启动时由内核解析。文件导入后正文独立保存在应用中，修改源文件不会改变已保存记录。系统选择器暂时遮住应用时保留本次选择，返回并恢复交互后继续；实际读取在后台按16MiB累计字节预算进行，大小未知的文件也可读取，超限或严格UTF-8解码失败则不保存。取消、离开原任务或整体恢复后，旧选择结果不再创建记录。配置与插件使用同一文件导入规则。

来源重复时，应用提示已有条目，确认后更新该条目，保留地址中的 query 和 token。首次本地保存且当前没有选择时选中该项。导入、新建及停止时保存都保持停止。

## 列表、选择与删除

配置卡片按窗口宽度排列为网格，按需构建可见部分。每列宽度有上下限，最后一行沿用正常列宽。卡片突出名称，其次显示来源或本地类型，底部显示更新时间／保存时间及操作，未知时间标为未知。

| 卡片区域 | 动作与显示 |
| --- | --- |
| 卡片主体 | 选择或切换配置，通过名称字重和描边表示选择 |
| 运行标记 | 标记实际core context使用的配置；LAN-only不显示VPN接管。保存正文与实际装载版本不同时另标旧正文 |
| 远程更新按钮 | 下载并更新该条目 |
| 本地编辑按钮 | 打开该条目正文 |
| 更多菜单 | 重命名、修改远程来源、自动更新、查看正文或删除等适用操作 |

更新、编辑和更多按钮分别响应点击、键盘焦点及读屏操作，执行时保持原配置选择。

VPN或局域网正在运行时，切换配置先保存选择并准备输入，再结束原core process，以新进程装载所选配置，保留两项开启意图。两者均未运行时只保存选择；异常待恢复时的更换配置也只保存选择，保持停止。启动失败或授权取消保留实际结果，确认旧资源已释放后才允许再次启动。

运行中的配置须先停止才能删除。删除所选配置后不再选择任何配置；要再次启动，先点击剩余配置卡完成选择。删除未选配置时保留原选择。停止时删除配置后仍保持停止。确认窗口说明删除后果。更新保留顺序；刷新或重新排列时，保留仍存在的可见卡片及其在屏幕中的位置。

## 更新与来源修改

远程项的“修改来源并更新”打开地址编辑，点击“保存并更新”提交。下载、解码及转换成功，且原条目没有改变时，来源和正文一起保存；ID、名称、顺序及策略选择保持。来源重复时保留输入并显示原因；下载等步骤失败时保留旧来源、正文和连接。

正文相同的来源修改保持原 revision。保存后的连接处理如下：

- 停止时保存正文，保持停止。
- 运行输入变化时，结束旧core process并尝试加载本次内容。
- 输入相同时保留当前连接；用户手动重试可再次应用已保存而尚未应用的内容。
- 应用失败时保留新正文，分别说明已保存和连接失败。配置来源表单收到已保存回执后关闭，通过记录ID、保存revision及storageEpoch读回核对新来源，应用错误交给全局SnackBar显示；不再用旧来源和revision重复提交。读回仍未确认时，从提示刷新列表，再打开对应条目核对；未保存失败则保留原表单输入。再次启动读取已保存组合。

## 插件列表与合成

插件按顺序显示，列表说明“上方优先”，提供逐项启停、前置／覆盖模式及上下移动。导入成功后默认开启。本地新建与文件导入都保存插件正文。

合成从列表底部向顶部执行，最上项最后生效。参与合成的每份正文须为单文档 YAML 映射，各文档的锚点互相独立。Compose读取合成所需的映射、别名和 merge key，其余值交 mihomo 解析；YAML 解码、编码与内核解析分别返回错误。没有启用片段时直接传入原字节。

| 结构 | 前置合并 | 覆盖同类设置 |
| --- | --- | --- |
| 映射 | 递归合并 | 递归合并 |
| 标量或类型冲突 | 使用插件值 | 使用插件值 |
| 普通序列 | 插件序列放前面 | 插件序列替换原序列 |
| 顶层 proxies／proxy-groups | 按精确 name 合并 | 按精确 name 合并 |

按 name 合并时，只处理两边都能唯一识别的非空字符串名称。同名项保持原位置，未修改项保持顺序，新项按片段顺序放前面。名称缺失、重复或无法识别的行分别保留，交内核解析。组内 proxies／use 使用普通序列规则。类型变化时保留其余字段；空命名序列保留原对象。覆盖 `rules: []` 清空规则，前置空序列保留原规则。

每份正文、启用片段的合计和运行YAML分别最多16MiB UTF-8。原文独立保存，不需要合成时直接传入原字节。应用合成、来源计算及默认值处理不额外执行age解密；proxy-provider的age-secret-key等字段原样交mihomo，由provider完成下载、解密、解析及缓存。字段来源与Android默认值见[内核合成](../architecture/core-integration.md#compose-and-android-configuration)。

插件正文、启停、排序、合并模式、增删和更新会比较当前运行组合，变化时应用本次修改；改名、更新周期和诊断读取保持现有连接。来源与正文在下载转换成功后一并保存，失败保留旧值。

## 局域网代理插件

“设置 → 局域网代理服务”将本功能保存为唯一的lanProxy插件，正文使用标准listeners YAML，enabled表示开启意图。默认mixed监听在同一端口提供HTTP和SOCKS5，开启UDP且不要求认证；配置中的其他认证、TLS及路由字段仍由mihomo执行。

便捷表单保存明确的本地地址、端口和UDP选项，每个地址生成独立命名监听。修改已知字段时保留未知字段；正文不能用表单表达时，继续从原文入口编辑，不重建为默认值。其他配置或插件里的监听不属于本功能，不被该开关改写或关闭。

该插件与其他插件沿同一合成顺序生效，正文及enabled包含在备份中，当前接口索引与实际监听状态不入备份。恢复后重新检查本机地址；地址失效时先选择当前地址再保存并启动。操作、连接地址与独立启停见[局域网代理服务](runtime-and-strategies.md#局域网代理服务)。

## 自动更新

远程配置和远程插件的更多菜单提供自动更新：

1. 打开对话框，修改开关与周期；标题下显示“保存后生效”。
2. 开启后选择每 6／12／24 小时。默认关闭，首次开启默认 24 小时；关闭时保留本次选择的周期并禁用控件，重新开启恢复该值。
3. 点“保存”提交；取消保留原设置。
4. 保存失败时保留对话框及输入，通过 SnackBar 查看原因和技术详情。

本地项通过明确保存更新正文。周期任务由系统按网络、Doze 和配额调度，开启时提示移动数据使用。已有操作未完成时延后执行；下载、解码、大小检查或保存失败时保持旧数据和连接。成功后只应用本次更新的实际运行项，VPN和LAN-only均按原输入定向重连，保留其他运行内容及两项开启意图；未运行的条目只保存，原先停止时仍保持停止。

最近尝试时间、结果和成功保存正文的时间分别显示。关闭或删除自动更新项时取消对应任务；用户停止、系统撤权或本次操作超时后，取消后续保存和重连请求。文件替换已经开始时，等待实际保存结果，保留并报告已经完成的保存。执行顺序见[周期更新](../architecture/android.md#周期更新)。

## Loon转换

远程插件下载后，识别到明确的 Loon section 时提取兼容 Rule。合法 YAML 映射保留原样，损坏 YAML 显示错误。Script／Rewrite／MITM／Host、未知及不兼容内容逐行转为注释，保留可读原文。

导入或修改来源时，代理名称默认空，“Loon IP规则添加no-resolve”默认关闭。选项随来源保存，后续手动和周期更新沿用；修改选项会重新下载转换，只保存转换正文。

填写代理名称时，替换兼容规则的普通目标，并为缺少目标的规则补入该名称；留空时保留明确目标，缺目标的规则转为注释。DIRECT、REJECT、REJECT-DROP、COMPATIBLE、PASS、PASS-RULE、GLOBAL保持。REJECT-IMG／DICT／ARRAY转为原生REJECT，并注释原动作。

支持已确认等价的DOMAIN系列、ASCII通配符、目的IP-CIDR／IP-CIDR6／GEOIP／IP-ASN、两种格式共有的端口条件，以及全部子条件兼容的AND／OR／NOT。FINAL、外部引用和未确认条件整条注释；no-resolve补到适用的目的IP条件中并保留已有参数。DNS行为和目标有效性由内核按配置检查。

生效规则保留顺序和重复项，没有生效规则时输出注释及`{}`。输入、输出分别限16MiB，注释转义处理FEFF／U+2028／U+2029；结果显示转换、注释及零规则数量。

## 正文编辑

本地正文在独立编辑页打开，远程正文使用相同阅读布局并显示只读。顶栏提供名称、返回和保存；正文支持等宽字、逻辑行号、字面查找、未保存标记、系统选区／剪贴板，以及硬件键盘剪切、粘贴、撤销和重做。软换行只改变显示。只读时可查找和选择，修改按钮与快捷键禁用。

选区或输入法组合文字变化时保留撤销历史；正文实际修改后建立新历史分支，替换原重做分支。容量、行长或记录变化导致操作被拒绝时，通过 SnackBar 显示原因。窗口高度较小时，正文可滚动，工具栏、键盘和保存按钮按剩余空间排列。

### 文本限额与换行

正文严格按UTF-8解码，含BOM最多16MiB，恰好上限允许保存。超过上限时拒绝本次修改，保留原输入。编辑／软换行另限每逻辑行32768个UTF-16 code units，查找输入总长使用同一上限；32769时拒绝整个新值。开头第一个BOM不计行长，正文中的FEFF计入；CR／LF／CRLF分行，U+2028／U+2029不分行。

超过行长的正文仍可无损导入、保存、应用和备份。正文页在创建编辑、查找或排版对象前检查，超限时以只读方式显示原文，并通过 SnackBar 提示行号及上限。每次修改或查找输入整体检查，拒绝时保留原值、选区及仍有效的 composing。系统文件提供者交付前的缓存由提供者管理。

没有编辑时，打开再保存保留首BOM、末尾和混合换行；选择、查找及软换行不改变正文。编辑后保留BOM及普通LF／CRLF风格。混合换行保存前确认统一为主要风格，数量相同取最早出现的风格；取消保留输入。只有提交的正文版本保存成功后，才清除对应未保存标记。

## 保存与退出

草稿保存在页面内存，点保存后写入文件。保存检查UTF-8、容量、记录ID、revision和storageEpoch，允许空白或无效YAML；加载时由内核解析。表单另外检查字段与局部原文修改，见[本地定义](local-definitions.md)。

| 结果 | 页面行为 |
| --- | --- |
| 停止项保存成功 | 返回，保持原选择和停止状态 |
| 运行内容变化 | 保存后结束旧core process，资源释放后加载修改内容 |
| 保存失败 | 留页保留输入，可修改或重试；旧记录及连接保持 |
| 已保存但应用失败 | 保留新正文，显示保存及应用结果；从原入口重试应用 |
| 结果未确认 | 保留页面内容，继续查询该次操作结果 |
| 带未保存修改返回 | 显示一次继续编辑／放弃选择，确认放弃后退出 |

顶栏按窗口、字号和保存文字分配空间；长名称限制显示宽度并提供完整名称。失败通过 SnackBar 提供错误详情，动作的触控区域至少48逻辑像素。等待、失败、重试和记录变化时，正文及保存按钮保持原位置。

记录被删除、正文被其他操作修改或整体恢复后，原编辑页停止保存并提示冲突，草稿仍可复制。新建记录的正文已保存而应用失败时，重试使用已经创建的ID和revision，继续应用该记录；详细结果见[操作身份与结果](../architecture/data-and-operations.md#操作身份与结果)。
