# 配置、插件与正文编辑

配置是完整mihomo文档，插件是全局有序的YAML映射片段。页面区分已保存正文、当前选择和实际运行组合，状态变化沿[运行规范](runtime-and-strategies.md#运行状态)表达。记录身份、发布与恢复机制见[数据契约](../architecture/data-and-operations.md)。

## 对象与来源

远程配置保存来源与下载正文，本地配置由应用管理正文，两者按保存顺序混排。远程更新成功后替换内容，远程正文只读，本地正文可编辑。来源支持HTTP／HTTPS，证书错误由正常TLS校验处理，重定向隔离来源凭据。

插件区分本地与远程，全局共用。普通本地插件与[本地自定义载体](local-definitions.md#载体与入口)均可全文编辑，正文历史与草稿按[产品范围](overview.md#范围边界)定义。

记录名称去首尾空白后非空，最多80 UTF-8字节，界面计数用B标明，超限保留输入并禁用提交。远程导入留空用来源主机名，文件导入用去扩展名的文件名；自动默认名超限取完整Unicode码点组成的预算内前缀。正文中的原生节点、组或provider名称由相应内核规则检查。

## 导入与新建

添加按钮直接打开URL导入、文件导入和本地新建的锚定菜单。

| 操作 | 保存与选择 |
| --- | --- |
| URL导入 | 下载／解码成功后保存；当前选择为空时选中，否则只新增候选；保持停止 |
| 文件导入 | 系统单文件选择，按实际字节读取完整正文；成功后直接返回列表 |
| 本地新建 | 先命名，再编辑最小直连模板；首个成功保存才创建，可直接保存未修改模板 |

保存接受空白与无效YAML，实际加载由内核检查。文件内容读取一次后成为应用管理的独立正文；取消或失败保留原数据，迟到选择沿原任务身份丢弃。导入输入采用完整mihomo配置格式。

重复来源提示既有条目，经确认更新该记录，并保留query／token。首个本地保存于当前选择为空时成为所选项，其余情况保留既有选择；保存操作保持原停止状态。

## 列表、选择与删除

主配置在局部工作区形成惰性网格，以最小／最大列宽控制操作距离，末行延续正常列宽。名称为主、来源／本地类型其次，底行时间与操作并排；远程显示更新于、本地显示保存于，未知时间明确未知。

选择采用勾号、稳定描边与语义，实际接管由运行状态表达。整卡单击选择／切换，更新、编辑和更多独立响应；菜单提供对应对象的适用操作。

切换先保存选择并准备输入，再正常停止原接管和启动目标；原停止时只保存。启动失败或授权取消后保持停止，后续启动以已确认释放为前提。

运行项在停止后可删除。删除停止状态所选项后，按保存顺序选剩余首项，末项删除后为无选择；这两种结果保持停止。删除确认实际后果，更新保留顺序，刷新和重排保存活阅读对象与偏移。

## 更新与来源修改

改源采用“保存并更新”。下载、解码、转换及身份复核成功后同时提交来源与正文，保留ID、名称、顺序和策略偏好；来源重复时拒绝并保留输入，失败保留原数据与运行。同正文改源保留正文revision，实际输入发生变化才应用。

保存后只应用本次目标与内容，需要变化时正常重连；停止时保存，同内容保留现有运行。用户可明确重试先前保存但应用失败的差异，周期任务按新内容应用。失败保留新数据并报告“已保存，连接失败”。

## 插件列表与合成

插件使用紧凑有序列表，明确“上方优先”，提供逐项启停、前置／覆盖模式和上下移动。导入成功默认开启；本地新建与文件导入采用插件正文。操作与列表顺序一致。

合成从底到顶，顶部最后作用。各文档独立解析锚点及merge key；重复键、循环／过量alias、非字符串键、多文档或过深结构整体失败。

| 结构 | 前置合并 | 覆盖同类设置 |
| --- | --- | --- |
| 映射 | 递归融合 | 递归融合 |
| 标量／类型冲突 | 插件值 | 插件值 |
| 普通序列 | 插件序列在前 | 插件序列替换 |
| 顶层proxies／proxy-groups | 按精确name融合 | 按精确name融合 |

命名序列同名保留位置，未提及保留顺序，新对象按片段顺序前置；组内proxies／use按普通序列处理。单文档名称缺失、重复或类型错误拒绝，跨文档同名才融合。类型变化保留其余字段交正式parser，空命名序列保留原对象；覆盖`rules: []`清规则，前置空序列保留原规则。

每份正文、启用片段合计及运行YAML的实际UTF-8预算各16MiB。原文独立保存，直接输入时返回原字节，保留公开age解密。来源及运行缺省见[内核合成](../architecture/core-integration.md#合成与平台投影)。

插件保存、启停、排序、模式、删除与更新按实际组合变化应用；改名、周期及诊断保持现有运行。来源修改和失败沿主配置同一规则。

## 自动更新

远程主配置与插件分别设置关闭或每6／12／24小时，默认关闭、开启默认24小时。本地项采用显式保存，周期对话框保持固定控件位置，关闭时周期占位并禁用。

系统调度受网络、Doze和配额影响，开启时说明移动数据使用。下载、解码、超限与保存失败保留旧数据和运行，已有操作占用时延期；成功后只应用本次运行目标，其余输入保留。停止保持停止，同正文保留本次已保存结果。

最近尝试、结果与成功正文时间分别显示。关闭或删除取消相应任务；用户停止及操作身份优先，发布和重连以同一有效owner为前提。机制见[周期更新](../architecture/android.md#周期更新)。

## Loon转换

远程插件链识别明确Loon section后提取兼容Rule，合法YAML映射保留原样；损坏YAML交错误反馈。Script／Rewrite／MITM／Host、未知及不兼容内容逐行注释，保留可读原文。

导入／改源提供默认空的代理名称和默认关闭的“Loon IP规则添加no-resolve”，选项随来源保存，后续改源、手动和周期更新沿用。修改选项重新下载转换，只保存转换正文。

填写代理名称时替换兼容普通目标并补省略目标；留空时保留显式目标，目标缺失的规则转为注释。DIRECT、REJECT、REJECT-DROP、COMPATIBLE、PASS、PASS-RULE和GLOBAL保持。REJECT-IMG／DICT／ARRAY转换为原生REJECT，并在注释记录原动作。

支持已确认等价的DOMAIN系列、ASCII wildcard、目的IP-CIDR／IP-CIDR6／GEOIP／IP-ASN、共同端口及全子项兼容的AND／OR／NOT。FINAL、外部引用和未确认条件整体注释；no-resolve补适用目的IP叶子并保留已有参数，实际DNS行为仍按配置，目标有效性由内核检查。

活动规则保留顺序及重复项，零活动规则为注释加`{}`。输入输出独立限16MiB，注释转义正确处理FEFF／U+2028／U+2029；反馈转换、注释与零规则的实际数量。

## 正文编辑

本地正文进入聚焦编辑页，远程正文复用阅读布局并明确只读。顶栏有名称、返回、保存；提供等宽字、逻辑行号、字面查找、未保存标记和系统选择／复制／粘贴，支持硬件键盘剪切、粘贴、撤销与重做。选区与输入法状态变化保留正文历史，新的正文修改替换重做分支。软换行只改变显示。只读保留查找与选择，修改动作和快捷键禁用。

正文能力限定为文本编辑、显式保存、系统选区／剪贴板、软换行和字面查找。拒绝与身份问题在稳定反馈位置说明原因，恢复正常后撤销对应动作与语义；短高布局协调工具、键盘和保存区。

### 文本限额与换行

正文实际UTF-8含BOM最多16MiB，恰好允许，超出整次拒绝并保留输入；严格UTF-8解码，接受空白和首BOM。编辑／软换行另限每逻辑行32768 UTF-16 code units，查找输入总长同限，32769整次拒绝。首个开头BOM不计行长，正文FEFF计入；CR／LF／CRLF分行，U+2028／U+2029不分行。

超行长正文保留无损导入、存储、应用及备份能力。正文页在创建编辑、查找或排版对象前检查，超限展示行号与上限原因；编辑及查找候选整次准入，拒绝保留原值、选区及有效composing。系统文件提供者在交付前的缓存按其自身实现处理。

未编辑往返保留首BOM、末尾与混合换行，选择、查找和软换行保留正文身份。编辑后保留BOM及普通LF／CRLF风格，混合换行保存前确认统一为主要风格，同数取首次；取消保留输入，脏标记只随实际提交版本清理。

## 保存与退出

草稿保存在页面内存，通过显式保存持久化。正文保存的准入检查包括UTF-8、容量与记录身份，接受空白及无效YAML；实际内核解析发生在加载阶段。GUI另执行字段及原文安全编辑检查，见[定义规范](local-definitions.md)。

| 结果 | 用户反馈与后续 |
| --- | --- |
| 停止项保存成功 | 返回，保持当前选择和停止状态 |
| 运行内容变化 | 保存后正常停止旧接管并加载本次修改；新版本启动以旧接管确实停止为前提 |
| 保存失败 | 留页保留输入，可纠正／重试；旧记录及运行保持原状 |
| 已保存但应用失败 | 保留新数据并说明实际结果；原入口明确重试，退出后保留已保存数据 |
| 结果未确认 | 保留事实并核对原操作的最终结果 |
| 有未保存修改返回 | 一次继续编辑／放弃选择；明确放弃后直接退出 |

正文顶栏按视口、字号及保存文案静态预算，长标题有界且可取全名。反馈保留独立48dp命中槽，等待、失败、重试、来源失效及恢复维持正文和操作锚点。已保存结果保留真实写入事实。

记录删除、正文变化或整体恢复后旧编辑身份撤销，保留可复制草稿并提示冲突。新建部分成功的重试接管已保存项，按[操作结果](../architecture/data-and-operations.md#操作身份与结果)结算。
