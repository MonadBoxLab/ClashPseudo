# 近期连接与辅助规则

从总览网络活动、常驻“连接”入口，或“设置 → 诊断工具 → 最近连接”进入同一任务。该页用于查目标、命中规则、分流路径和连接流量，也可断开单条连接或从目标新增规则。

查找记录时先输入域名、IP或端口，再组合活跃状态和规则筛选，点击记录打开详情。入口切换保留搜索、筛选、选择和阅读位置，分栏规则见[集合与详情](interaction.md#集合与详情)。

## 观察范围

实际转发context运行期间，AppRuntime持续读取VPN及局域网入口的连接，排除内核标记为Inner的记录。页面显示已保留窗口；内核停止或异常退出后停止采样，保留记录及已打开详情至过期，新context建立时重建窗口。没有运行转发时不为列表创建预览。记录只保存在默认应用进程内存。

展示最近开始的最多1000条活跃、500条失活与至多1条当前详情；失活记录从首次确认失活时起保留15分钟。容量淘汰、失活、读取失败与结果不完整分别处理，失败时保留原记录及原始错误。

采样分别调用Range和Get，并非同一事务；短连接或拒绝可能发生在两次采样之间。失活表示采样时已找不到原活跃记录，结束时间、原因和最终流量以返回数据为准。一条复用连接可承载多个HTTP请求，列表每行仍对应一条连接。

## 列表与筛选

列表按开始时间倒序，同时间按ID稳定排列。目标、实际分流路径与辅助信息分层，协议、状态和上下行累计紧凑排列。实时数值更新保留顺序，按窗口宽度和字号拆行；插入、淘汰、名称变化与重排保存仍存在的可见条目及其在屏幕中的位置。

| 工具行入口 | 筛选内容 |
| --- | --- |
| lifecycle | 全部／活跃／不活跃 |
| 命中规则 | 选定规则；“全部规则”解除该条件 |

两条件与搜索共同生效。入口显示当前条件和箭头，打开锚定菜单；长规则换行并内部滚动，为勾选图标预留固定宽度。菜单打开期间固定选项，保留暂时没有记录的已选规则。容量限制显示实际 limited／omitted 数据；自动读取失败使用列表和详情共用的 SnackBar。

实际条件改变才返回列表顶部，取消菜单、选择原条件或查询内容未变时保留位置；详情往返保留条件和阅读。相邻行之间绘制分隔线，列表按需构建可见部分。

## 搜索

AppBar提供搜索动作，进入时在原AppBar高度内显示SDK输入框，过渡约200ms，减少动效直接切换。输入左侧为搜索图标、右侧为X，页面原返回动作保持。

搜索保留原始输入和输入法组合状态，另外去掉首尾空白作为有效查询。不区分大小写，逐字段匹配域名、IP／端口、分流路径与规则。记录须同时满足搜索、lifecycle和规则条件；条件持续匹配业务采样更新后的记录。

原始输入非空（含纯空格）时，X清空并保留搜索与焦点；输入已经为空时退出搜索并收起键盘。返回先收键盘，再退出搜索；退出清查询、保留筛选。打开菜单／详情释放输入焦点，返回保留输入和阅读。搜索框开始关闭时停止响应输入，并从读屏内容中移除。

## 详情

首次进入保持无选择，详情由用户选择触发；空间充分时并排，否则逐页。开合与布局拆合保留连续过渡、同一Controller、读取请求及阅读位置。筛选排除所选对象时保留详情，失活、删除或来源失效时保留最后内容并禁用针对原记录的修改操作。

详情按目标摘要、分流、流量、时间和连接信息分层。协议与端口靠近目标，活跃／不活跃及已断开结果使用简短标识。路径、规则和图标来自该连接观察，域名缺失时显示真实IP／端口，IPv6加方括号，端口显示一次。

必要缺值为“—”，首次无值的可选字段省略；后续新字段追加在连接信息末尾，已出现字段再缺失时原位标未提供。长值可选择及内部滚动，首次内容确定最大阅读高度，后续内容增加时在该范围内滚动。字段名和值对齐，成对上下行数字与单位分层；大字号可纵排。

速度由同一会话、同一连接的累计差及有效采样间隔计算。某一方向差分无效时，该方向显示“—”；已确认零值才显示0 B/s。时间显示连接开始时刻，以及最近一次有效采样对应的持续时长。活跃记录使用绿色，失活记录使用中性色，并同时提供文字或形状。DIRECT使用类别色。

读取错误、断开错误和规则来源错误从详情 AppBar 的“更多操作 → 错误详情”查看。详情触控区域至少48逻辑像素。没有记录时显示空集合或筛选无结果。

## 读取状态与错误详情

列表和详情 AppBar 保持固定的“更多操作”按钮。列表菜单承载“清除已结束记录”，详情菜单承载“断开连接”；仅在有实际错误时增加所属菜单中的“错误详情”项，不增减工具栏按钮。成功读取后，读取错误及对应菜单项消失；断开和规则来源错误按各自结果保留。

自动读取失败时，工作区底部出现一条持久 floating SnackBar，包含简短摘要、“错误详情”和关闭按钮。窄屏列表、窄屏详情及宽屏双栏共用同一提示；有 NavigationBar 时在导航栏上方，有 NavigationRail 时位于 rail 右侧工作区，居中且最大宽度560逻辑像素。字号较大时摘要和操作换行，局部空间不足时暂缓浮层，仍可从 AppBar 的更多菜单查看错误详情。

1. 点击 SnackBar 的“错误详情”，查看点击时捕获的完整错误。Dialog 不被之后的轮询内容改写，技术详情保留原始 cause、stack、suppressed 和未知字段，并支持复制。
2. 点击关闭、向下滑动关闭或查看详情后，同一轮持续失败不再自动弹出。需要再次查看时，点击列表或详情 AppBar 的“更多操作 → 错误详情”；此时打开的是当前错误，不是历史队列。
3. 明确成功读取后撤下提示；随后再次失败可重新通知。暂时隐藏页面或清空 error 不表示恢复。切任务、被其他页面或 modal 覆盖、菜单打开或应用不可交互时撤下提示；返回同一来源后，未查看故障在有效读取再次确认后可显示，已关闭故障保持安静。core、会话或 storageEpoch 替换后，旧 action 和待显示回调失效。

SnackBar 显隐不移动筛选、AppBar 和列表 viewport，不改变搜索 focus、selection 或 composing。错误出现或恢复不改变搜索框宽度、AppBar 动作位置及高度；正文不预留错误行或永久尾部空白。floating SnackBar 会暂时覆盖底部少量正文，立即关闭后可完整阅读和操作最后一条记录与详情末尾。清除已结束记录和释放详情产生的错误仍从“错误详情”查看，不自动显示为读取异常；主动断开和新增规则失败使用所属工作区的 SnackBar，技术详情只在用户点击后打开。

找不到目标时，清空搜索并解除两个筛选，再检查VPN／局域网服务及实际读取错误；窗口淘汰及新core context建立时重建窗口，仍按观察范围处理。

## 单条断开

在详情右上角打开“更多操作”，点击“断开连接”，只作用原会话的精确连接ID。处理中菜单按钮原位显示进度，断开菜单项禁用并防重复，留在详情；断开图标使用警示红，失活或不可确认时禁用该项，工具栏尺寸保持。

断开结果分为closed、absent、failed和未确认：已关闭与原本不存在分别显示；失败可打开本次连接关闭的错误详情；等待超时或身份变化后继续核对原调用结果。VPN、局域网服务和其他连接继续运行，详情按原连接持续读取。

## 从连接新增规则

新增规则在分流卡片，优先位于“命中规则”标签行右侧，主按钮与范围箭头成组，规则正文下一行占完整宽。仅实际语言、字号与宽度容纳不足时整组移到正文下左侧；操作过程中按钮和文字保持原位置。

候选来自同一 core context 中取得的完整 host 或非 fake-IP 的 DstIP，包含 VPN 及局域网入口：精确 DOMAIN、公开后缀边界内的 DOMAIN-SUFFIX、IPv4 `/32`／IPv6 `/128` 单地址。后缀含 private 边界；完整观察时生成候选，连同当时的 processId、inputId 及内核来源保存在连接记录中，并受记录容量限制。后续样本缺少有效候选时保留原候选，展示截短值仅用于显示。

规则目标提供当前有效的全部策略组及 DIRECT／REJECT，包含主页隐藏组。默认使用精确域名，IP 候选使用对应原生类型；点击后打开既有[规则表单](local-definitions.md#规则)，保存步骤相同。连接结束后仍可从保留候选新增规则，断开操作只用于活跃连接。读取目标和提交时，核对原 processId、inputId、完整内核来源、有效目标及 storageEpoch。来源被替换、数据恢复或 core context 变化后，原菜单和 callback 不再提交；等待时保留按钮位置，禁用原因可点击查看并供读屏读取。

## 刷新与过期

可见时约每秒单请求读取，失败按1／2／5／10／30秒退避。并排集合与详情都更新；覆盖或隐藏暂停对应UI读取，失焦仍保持页面可见的状态和连接数据，装饰动效按[可见性规则](interaction.md#可见性与交互)处理。

刷新时保留选择、查询及仍存在的可见记录。读取失败保留错误，原会话结束后禁用对应修改操作；同名新连接按新记录处理。大小及并发限制见[连接与流量接口](../architecture/core-integration.md#connections-and-traffic-api)。
