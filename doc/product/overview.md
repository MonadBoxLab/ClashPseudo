# 产品任务与范围

Clash Pseudo 使用 mihomo 执行配置，在 Android 上通过 VPN 接口接管应用流量，也可独立向局域网设备提供 HTTP／SOCKS5 代理。用户自行提供完整配置及其引用资源，应用提供配置保存、运行控制、策略选择、连接观察与诊断。VPN 与局域网服务分别启停；内核退出后保留当前页面、草稿和已完成保存，由用户重新启动、更换配置或逐项清理文件。

Android 分发包含 armeabi-v7a、arm64-v8a、x86_64，最低系统版本由所选 Flutter SDK 和 Android 构建配置确定。平台实现见 [Android 接入](../architecture/android.md)，构建及分发见[构建与测试](../development/build-and-test.md)。

## 功能范围

| 用户任务 | 界面入口 | 行为规范 |
| --- | --- | --- |
| 启停接管、切换模式 | 总览；设置的“连接行为”组 | [运行与策略](runtime-and-strategies.md)：授权、状态、计时、模式及重连 |
| 向局域网设备提供代理 | 设置 → 局域网代理服务 | [局域网服务](runtime-and-strategies.md#局域网代理服务)：本地地址、HTTP／SOCKS5、UDP、独立启停及实际监听结果 |
| 处理内核退出 | 当前工作区的中断提示 → 错误详情 | [恢复操作](runtime-and-strategies.md#内核退出与恢复)：重新启动、更换配置及逐项清理文件，保留页面与草稿 |

| 导入、选择、更新或编辑配置 | 设置 → 配置与数据 → 配置管理 | [配置与插件](configurations.md)：完整配置、本地正文、来源与自动更新 |
| 管理全局复写片段 | 设置 → 配置与数据 → 插件（复写） | [配置与插件](configurations.md#插件列表与合成)：启停、排序及 YAML 合成 |
| 创建节点、组、规则和 provider | 设置 → 路由与资源中的对应分类 | [本地定义](local-definitions.md)：专用插件、表单、原文编辑及删除 |

常驻导航按窗口容量显示总览、策略、连接、配置与设置中的三至五项；设置目录可进入全部任务。从两种入口打开时保留同一页面状态、草稿、搜索和阅读位置。布局、键盘、反馈与可访问性要求见[通用交互](interaction.md)，文件写入及资源由谁创建和释放见[应用架构](../architecture/overview.md)。

## 信任与隐私

配置、provider、资源更新与图标请求使用各自声明的来源。配置可包含节点凭据、下载令牌、外部路径和网络行为；Android 沙箱决定文件访问范围，内核执行范围见[公开能力边界](../architecture/core-integration.md#public-api-boundaries)。

应用不采集或上报用户数据。已安装应用名单用于本地应用访问设置。配置URL、节点凭据、DNS响应、连接记录、日志和备份可能包含敏感内容：URL及表单中的密码、令牌等字段提供隐藏显示，复制和导出保留完整内容，界面在相应操作处说明所含数据。

### 隐私与许可入口及提示

“设置 → 关于 → 隐私与许可”提供完整说明、随包 GPL 正文及完整可选择复制的仓库 URL；第三方许可由 SDK LicensePage 展示。首次短提示提供“完整说明”和“我已了解”，两处 GPL 入口均可离线打开。

安装提示的记录流程：

1. 读取noBackup目录中的本次安装提示标记。
2. 无标记且应用可交互时显示短提示；提示实际进入前台可见frame后，尝试写入标记。
3. 写入成功后，正常重开、进程重建及保数据升级保留标记。清除应用数据或重装后重新提示。仅后台启动时保持未显示状态。
4. 读写失败时显示“未能确认提示记录已保存。下次打开可能再次显示。”及可查看的提示标记读写错误；启动与停止仍按各自运行条件操作。

该标记独立于用户偏好，业务备份与恢复不迁移它。文件格式与同步步骤见[安装级提示标记](../architecture/android.md#安装级提示标记)。

### 数据表达

| 数据 | 界面表达 |
| --- | --- |
| 保存、选择、应用、运行 | 配置卡以字重和描边表达选择，实际运行配置另有状态；正文保存结果、应用结果和总览接管状态分别显示 |
| 未知、过期、未测、空集合、零 | 按实际内容表达；缺值显示“—”，已知零值使用 0 及单位 |
| 失败或部分完成 | SnackBar 显示已保存／已恢复内容、连接结果和下一动作；错误详情保留实际错误、`cause` 和 `suppressed`，支持复制 |
| 网络活动 | 以连接为记录单位，活跃状态、命中规则及观察到的分流路径分别展示；缺域名时显示 IP／端口 |
| 应用名称、图标、资源时间和能力 | 使用所属来源的值，缺项标未知或不可用 |
| 延迟 | 对应页面所列 HTTP 目标的实际调用结果 |

## 范围边界

应用使用单一 mihomo 内核，管理完整配置、全局复写片段和本地定义，使用与分发免费。Loon 插件按[转换规范](configurations.md#loon转换)提取兼容规则，其余行保留为注释。

数据按以下lifecycle保存：

- 配置、插件和偏好显式写入三份业务文件；正文编辑草稿保存在页面内存。
- 最近连接和日志保存在默认应用 process 的有界内存窗口中。连接的失活记录从首次确认失活起最多保留15分钟；core process 停止或异常退出后仍可阅读保留内容，默认应用 process 结束后窗口消失。日志同时受条数及字节预算限制。
- Geo、provider 缓存与协议身份由内核目录和对应协议管理；业务备份仅包含三个正式业务文件。
- 系统 VPN 授权、Always-on、系统备份与调度分别使用 Android 的系统机制。

配置、插件和偏好文件的字段及大小限制见[数据与操作](../architecture/data-and-operations.md)，分发许可、第三方通知和对应源码见根 [NOTICE](../../NOTICE.md)。
