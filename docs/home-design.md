# 应用页面设计依据

本文面向项目维护者，保存已认可的具体页面结构、状态表达与动效约束，当前涵盖总览、模式入口、策略页及连接列表与详情。全应用的视觉与交互遵循[通用设计原则](product-requirements.md#通用设计原则)，同样适用于配置管理、弹窗和后续新增页面；本文的具体布局不作为其他页面的统一模板。覆盖总览、策略组、连接及相关子页面的阶段性参考见[离线原型](prototypes/product-preview.html)，当前平台能力与开发命令见 [README](../README.md)。

## 结构与主题

- 主导航为总览／策略，使用保留页面与滚动位置的双页壳；配置管理从两页进入同一二级路由。首次构建隐藏策略页不触发加载。切 tab 明确暂停首页波纹及隐藏页策略读取，不把切 tab 当作应用进入后台。
- 首页同时承担控制与观察，不以两张空卡片代替信息组织。顶部配置行连接配置管理，中央圆形按钮承担启停；状态文字作为辅助，不与按钮争夺视觉中心。
- 主区吸收剩余高度，网络区按内容定高；短屏和大字体允许整页滚动。首页由中央状态表达启停成功，不重复显示“接管已启动／接管已停止”，也不为其保留空白反馈区。错误、风险确认及配置操作结果显示在主区底部，长内容可自然展开，不截断；配置管理页反馈保持完整。主区与分界圆角背面共用同一过渡底色，普通启停不推动分界。长配置名截断，但不挤掉管理入口。正式界面使用系统安全区，不绘制手机壳或假系统栏。
- 首版默认朱砂色，跟随系统深浅主题，不增加换色设置。夜间独立定义主区、按钮、文字、波纹、内容面与选择态，而非简单反色；这不是永久品牌色冻结。
- 配置管理及弹窗沿用同一主题，保留现有列表组织、风险确认与操作规则，不因首页迁移重做配置流程。

## 状态与配置身份

- 初次读取显示正在获取状态／正在读取配置，不以默认空集合推定没有配置。后续健康同步静默更新，同值不重播过渡。
- 运行时顶部优先显示实际加载项，停止时显示当前选择；实际项与选择项或保存版本不一致时补充说明。仅在初次读取结束、平台状态为 `UNKNOWN` 且已有选中配置时显示“已选配置 · 未确认实际使用”；正常启动、停止和授权等待不显示这条提示。身份说明保留至少一行空间并使用短文字过渡，避免插入或移除时推动主区。
- 配置读取失败时不猜实际名称，也不显示假空列表。管理页可以展示明确标注的上次记录；已确认运行且没有冲突操作时仍可停止，但不能据旧数据启动或修改配置。
- 系统授权等待使用实际操作说明，不显示为内核已经启动。启动失败且清理完成仍是关闭并附错误；原生清理无法确认则保持未知，禁止冲突启停。
- 空配置提供独立导入入口，电源按钮不暗中变成导入按钮。保存正文失效时禁止启动，提示重新导入更新。

## 自动读取与恢复

初始化、平台变更通知、恢复前台及命令完成后读取真实状态；界面不提供要求用户手动核实的入口，也不因读取而提交启停。

平台快照与配置读取阶段各有 5 秒期限。读取失败时仅在前台按 1、2、5、10、30 秒退避重试，之后封顶 30 秒；全部恢复后不再定时轮询。后台取消重试，恢复前台立即读取。请求合并与本地代次检查隔离超时、操作切换、后台及销毁后的迟到结果；超时不等于底层 Future 已取消。

读取成功但平台返回 `UNKNOWN` 不属于通信失败。自动读取不承诺修复原生资源清理失败，不新增强制重置或恢复机制。平台、配置与命令错误分别保留，读取成功不能吞掉命令提交失败。

## 动效与生命周期

- 确认运行后，第一圈从按钮边缘发出，约每 2 秒加入一圈，每圈约 6 秒向外扩散淡出。禁止用负延迟制造远端突然出现的初始圈。
- 停止请求开始后不发新圈，已有圈继续向外扩散，同时在约 1.5 秒内平滑淡出，不冻结半径，也不等待完整的 6 秒扩散周期结束；业务状态和按钮不等待动画结束。停止背景上的波纹颜色同步过渡，避免收尾突然消失。
- 快速重新启动时，旧圈继续原来的淡出，不重置计时或重新激活；新圈从源点加入。后台、路由覆盖、主区不可见或减少动效时清理波纹；重新可见且仍运行时从源点恢复，不补播积压帧。
- 状态、按钮标签与辅助文字采用约 100ms 退出、180ms 进入的过渡，避免叠字；空副说明保留一行空间。同值不重播，快速变化不让旧回调覆盖新状态。内容高度仍可随错误、导入引导及配置身份说明变化，不固定整页文本高度。
- 波纹使用局部绘制和独立重绘边界，不逐帧重建整页。减少动效时关闭波纹与文字过渡，语义状态立即更新。

## 模式入口

状态区的模式文字打开三选一底部浮板，沿用系统深浅主题、安全区和可滚动布局。运行时选中实际模式，停止时选中保存模式并标注未运行；没有配置也可在停止时预选。规则、全局、直连的业务规则见 [运行模式](product-requirements.md#运行模式)。

浮板采用暖白／炭灰中性底板，选项为适度圆角的行式卡片，分别以分流路线、地球、直向箭头辅助识别。名称与次级灰色说明拉开文字层级；选中项仅用很淡的暖色底，朱砂强调集中在小型图标区与勾选标记，不使用大面积粉红填充或鲜红描边，不只依赖颜色表示选择。

点击后保留已确认选中态并显示等待，保存与实际结果确认后关闭浮板；失败留在浮板说明，不乐观打勾。保存值与实际值不同时，入口仍显示实际值，浮板说明保存值供下次启动使用。模式读取失败单独表达，不把 VPN 显示成已停止，前台沿用既有退避重读。浮板覆盖时暂停波纹，用户关闭浮板不取消已受理操作。

首页与模式浮板以当前模式／预选说明表达成功，不再重复显示“运行模式已切换”“运行模式已确认”“模式已保存，下次启动生效”，也不保留空白占位。只过滤明确成功，等待、错误、保存但应用未确认和 HTTP 风险确认均保留；配置管理页仍展示完整结果。

## 策略页面

组摘要采用紧凑网格，突出组名和当前成员；类型弱化、固定意图用小标记，成员数放到浮窗。普通字号保持统一卡片节奏，窄屏与大字体按空间减列并增高。组图标采用表达真实类型的本地多色／双色图形，名称中的 emoji 保留自身色彩，不猜测地区或添加模拟延迟。

点击卡片原位展开唯一成员浮窗，表面、图标和标题保持来源关联，背景适度变暗；来源卡片保留网格占位，关闭后恢复。只有“组卡片 → 成员浮窗”一层，成员组只可选择和查看直接当前成员摘要，不提供继续进入的箭头、子层返回或叠窗。调整其他组从主网格打开对应卡片。系统返回、关闭按钮或点击窗外均关闭浮窗，选择后保持打开。

浮窗为紧凑单列成员行，名称与次级摘要分层，选择标记对齐，选中底色留边距；长列表内部滚动，关闭入口持续可达。展开与收起考虑安全区、尺寸变化和来源失效，减少动效时直接呈现，不向已经离屏或失效的卡片回放过渡。

页面和浮窗以暖白／炭灰为底，朱砂用于交互强调，不限制图标色彩。停止状态仅在页面标注“未接管 · 预选”；正常界面不常驻防御性机制解释。错误、等待、未恢复及保存与实际不一致在发生时明确显示。负载均衡无唯一选中项；上下文换代或读取失败时撤销旧数据的可操作性，不乐观更新。

页面可见且前台时立即读取，正常每 5 秒更新；失败按 1、2、5、10、30 秒退避。二级配置页覆盖时暂停读取，成员浮窗打开时继续；关闭浮窗不撤销已受理操作。失败的完整加载提供明确重试，不与读取重试混为自动加载循环。预览生命周期与网络边界见 [Android 接入](android-native-integration.md#预览上下文与策略接口)。

## 连接列表与详情

总览网络区的“查看连接”进入二级列表，详情为下一级页面；保持总览／策略双主导航。沿用离线原型的信息层级，不把连接放进浮板，不同时增加速度曲线或第三个 tab。

列表采用紧凑行，目标优先、实际路径次之，开始时间、协议和已观测上下行累计值作为辅助。初始按开始时间倒序，同时间按 ID 稳定排列；流量更新不重排，插入与移除尽量保持可见存活条目的位置。规则筛选可清除，详情返回保留条件和滚动位置。仅有活动列表，不放无来源的历史、已结束或已拒绝切换。

详情顺序为目标、分流结果、活动与流量、连接信息。链和规则来自该连接，不用当前策略选择重算；域名缺失时用真实目标 IP／端口，IPv6 端点带方括号。当前详情失活保留最后观察内容，失败、暂停、停止和换代分别表达。数据来源说明折叠显示，不在正常页面堆常驻机制说明；长文本可换行，大字号时字段改为上下布局。

列表与详情共用读取，正常约每秒一次、单请求在途，失败按 1、2、5、10、30 秒退避。后台或其他页面覆盖时停读，返回立即重读；暂停展示不停止可见期间读取。产品边界见[首轮连接观察](product-requirements.md#首轮连接观察边界)，回归见[连接测试](../test/features/connections/connections_test.dart)。

## 能力边界与检查方法

当前首页接入真实配置、启停与模式选择，策略为独立导航页；网络区提供活动连接观察入口，没有模拟数字、零值曲线或占位导航。速度趋势、完整历史与拒绝采集仍未接入。完整生命周期验收仍受 [原生资源问题](android-native-integration.md#当前边界) 阻塞，界面可操作不等于全部配置错误路径安全。

自动化回归覆盖读取超时与退避、迟到结果隔离、配置身份、未知与读取失败、HTTP 风险确认、窄屏与大字体、深浅主题，以及波纹收尾、快速重启、文字中间帧和动画清理。相关测试位于 [controller 测试](../test/app/app_controller_test.dart)、[首页测试](../test/features/overview/overview_page_test.dart)和[动效测试](../test/features/overview/home_motion_test.dart)。

设备检查使用 [Android 受控测试端](android-native-integration.md)，不使用私人订阅：

1. 导入新来源，确认有当前项时只新增候选；选择后仍停止，再显式启动。打开配置页、返回及恢复前台不能重复启动。
2. 运行时离开界面，检查 VPN 保持运行且业务服务不残留；回前台核对真实状态，再正常停止，检查服务释放，不以强制结束进程代替停止。
3. 请求受控端不存在的路径，检查 HTTP 错误反馈、不新增记录且不改变当前选择；重新导入正确来源可继续操作。
4. 检查首圈从按钮边缘发出、停止后已有圈继续扩散且在 1～2 秒内淡出、快速启停无远端突现；启停中检查分界位置和圆角背景无跳动或闪色。页面不可见时检查动画／重绘是否停止。截图只能验证外观，不能代替帧耗时与 CPU 测量。
5. 系统授权取消、深浅主题、大字体和减少动效需在允许相应设置变更的环境检查。自动化覆盖不等于这些设备场景已经验收，单一模拟器也不代表 ARM64 真机或其他 Android 版本。
