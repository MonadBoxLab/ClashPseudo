# 产品需求与体验方向

本文保存产品目标与操作规则，不表示功能已经实现。已认可的首页结构与首轮边界见 [首页设计依据](home-design.md)，完整流程参考见 [离线原型](prototypes/product-preview.html)，目标平台与当前能力见 [README](../README.md)。

## 1. 目标与边界

- 优先轻量和快速启动，关注内存、CPU、包体积及后台开销；资源表现需实际测量，不以语言或框架名称代替结论。
- 导入完整 mihomo 配置后简单使用，同时提供策略调整、分流检查和必要诊断。
- 精致感来自清晰的信息层级、视觉一致性与自然过渡；可靠感来自即时反馈、真实状态、稳定布局和可恢复错误。视觉表现不代替网络与平台验证。
- 优先使用完整配置 URL 及其已有策略组、规则，不静默猜测或转换节点订阅。
- 不建设多内核框架、通用配置转换系统、独立防火墙或带宽调度。不依赖付费开发或分发服务。
- 采用务实信任模型：信任用户选择的完整配置来源及其 provider 和后续更新；仅使用可信来源。控制接口、监听范围等平台字段及客户端凭据保护由应用管理，但不承诺对恶意完整配置提供严格的本地文件沙箱隔离。具体保护范围见 [Android 接入边界](android-native-integration.md#当前边界)。

## 3. 运行与配置规则

### 运行状态

- **关闭**：接管已确认停止，不是仅停止内核。
- **等待**：请求已受理、结果未确认；系统授权等待单独说明。
- **运行**：必要服务和接管组件已就绪，不表示所有目标可达。
- **未知**：无法核实状态，不能显示成正常或关闭。
- **异常阻断**：接管仍持有且符合明确的阻断条件，不能根据普通错误猜测。
- **直连模式**：按直连模式处理流量，不等于关闭接管。

模式和策略变更先显示等待，确认后更新；失败不伪造成功。界面打开或恢复时自动获取真实服务状态，不把本地记录当作当前事实，不要求用户手动核实。初次读取明确等待，后续同值同步不重播加载；读取失败时仅在前台退避重试，恢复前台立即读取，不自动启停。成功读取到平台未知状态不等于通信失败，也不承诺通过重试修复原生资源清理失败。

### 运行模式

客户端统一保存规则、全局、直连三选一，首次默认 `rule`，没有“跟随配置”入口。启动、换配置及当前配置更新后的重新启动，都用该值覆盖运行副本的 `mode`，下载原文不变。关闭时也可预选，只保存、不启动；运行中热切换默认不主动断开已有连接，新连接按内核模式处理，旧 TCP 连接／UDP 映射不承诺重新路由。全局使用 `GLOBAL` 策略，不等于必然经过代理。

运行时显示查询到的实际模式，停止时显示保存值并标注未运行。先保存再应用：保存失败不改内核；保存成功但应用未确认时明确说明保存值供下次启动使用，不自动回滚、重发或停止 VPN。模式读取失败不改变已确认的接管状态，仍可停止，前台自动重读。后续设置可细化是否主动断开连接，本轮不增加开关。

### 策略选择

- 停止时允许查看当前配置的真实策略组并预选，不要求先启动 VPN，不把上次缓存冒充已加载上下文。只打开总览不完整加载内核；首次进入策略页或显式启动时按需加载。
- `select` 支持手选；`url-test`、`fallback` 支持固定成员及恢复自动；`load-balance` 只读，没有唯一当前成员。自动组选出的临时成员不是固定偏好。
- 每配置独立保存组类型及固定／自动意图，同名组不跨配置覆盖。先保存再应用，读回确认后更新；保存失败不应用，应用未确认时保留保存值并明确说明，不回滚、重发或停止 VPN。选择后留在成员浮窗；关闭浮窗不撤销已受理操作。
- 重新加载时，保存的组、类型或成员失效，遵循配置默认／自动行为并提示未恢复；保留原偏好，不猜替代、不阻止整份配置启动。默认可能为 DIRECT，不保证一定代理。更新正文保留偏好，删除配置一并删除偏好。
- 切换不主动断旧连接、不重启 VPN，新连接按新策略处理。后续共用设置统一控制模式与策略切换是否断连接，本阶段不增加开关。
- 过滤 `hidden` 组。GLOBAL 在全局模式显示、直连模式隐藏、规则模式仅被其他组或规则引用时显示，显式 hidden 优先；直连模式不隐藏整个策略页。
- 已加载预览在前台切页时复用；未接管且界面真正不可见后保留 30 秒，再尝试释放。运行 VPN 不受此回收影响；暂停／失焦不等于不可见。系统冻结时不保证准时释放，宽限期间配置自身网络任务可能继续。
- 策略页可见且前台时读取真实数据；读取失败标注过期并禁用旧数据上的修改，不妨碍已确认运行的 VPN 正常停止。准备失败由用户明确重试，不自动循环加载。
- 首轮不包含主动测速、延迟排序、策略编辑、批量操作、自动优选或远程图标，不虚构地区和延迟。

### 配置操作

已保存正文、当前选择与实际加载必须区分：停止时仍可有当前选择，但不代表已经运行。

1. **导入**：下载和保存成功后加入列表；无当前项时选为当前，否则只新增候选，不自动启动。失败不新增、不影响已有项。不做完整预校验，保存不保证可加载，实际进入策略预览或启动时由 mihomo 解析。重复 URL 提示已有项，经确认可覆盖更新，不新增条目；来源身份保留 query/token。
2. **选择与切换**：停止时选择有保存正文的候选仅改变当前项。运行时先停止接管，确认停止才选择并尝试启动目标；配置错误可能在停止旧运行后才发现。启动失败或授权取消保持停止，不自动恢复旧配置；停止失败或状态无法确认时不启动目标。
3. **更新**：成功替换唯一保存正文；当前项正在运行时停止后使用新正文启动，停止时仅保存。确认更新后先持久化旧正文失效状态，再开始下载；此后更新失败或途中进程结束，旧正文仍不可启动。若最初的失效状态无法写入，更新不开始，明确报告旧记录未修改，不能宣称已持久化禁用。当前项更新失败时停止正在运行的接管，不自动选择其他项；保留名称和来源供重试。候选更新失败不停止当前运行。新正文是否可运行由实际启动结果决定。
4. **停止**：确认接管及资源释放，不等于仅停内核。失败时保留实际或未知状态与恢复入口，不误报已停止。
5. **删除**：运行中不能删除当前使用项，其他候选可删。停止时删除当前项后选择剩余列表第一项，不启动；该项无效时仍选中但不可启动。最后一项删除后无当前选择。列表按保存顺序稳定排列，更新不重排；删除需确认后果。
6. **重开与冲突**：恢复保存项和当前选择，再核实服务状态；打开界面不自动启动。启停、切换、更新等待及状态未确认期间禁止冲突操作；返回页面不取消已受理的操作。

不保留配置正文历史、旧版本备份或回滚副本；内核运行资源与缓存另行定义。复写后候选与实际生效内容也需区分。

主配置 URL 支持 HTTPS 和 HTTP；HTTP 请求前明确确认风险，HTTPS 证书错误不绕过，重定向不能静默降级。保存远程原文不变；实际运行时监听端口、控制接口和 TUN 等平台字段由应用管理，不因普通配置包含这些字段就整份拒绝。provider 初始加载失败是否阻止运行遵循 mihomo 行为。

### 系统备份与恢复

配置正文、来源、保存顺序、当前选择、每配置策略偏好和客户端模式具有恢复价值，可参与受保护的 Android 系统备份／迁移；缓存、临时输入、任务与运行状态不备份。Android 12+ 云备份要求系统具备客户端加密能力，Android 9–11 使用相应的条件规则，更旧版本不备份敏感配置。系统是否执行备份受设备、账户、配额及系统实现影响，不保证一定可恢复，不自建云同步或配置历史。

恢复只恢复配置、选择与保存模式，仍须查询真实状态、按需授权并由用户显式启动。

## 4. 页面与交互方向

- 当前主导航只有**总览／策略**两个真实入口；不放连接或设置占位，不预设未来连接页一定占第三个 tab。
- **总览**：状态与启停优先，配置和模式集中呈现，流量区展示上下行与趋势。配置管理为二级页面，不增加主导航入口。
- **策略**：以突出组名与当前成员的紧凑网格组织信息，从父卡片原位展开单层成员浮窗。浮窗内成员组只可选择和查看摘要，不允许继续展开；调整其他组回主页面打开对应卡片，不使用底部浮板或递归叠窗。区分手动选择、自动组固定与恢复自动；负载均衡不虚构唯一当前成员。测试若解除固定，必须明确说明，不能在失败后假装旧固定仍生效。
- **连接**：以目标和实际分流路径为主，提供生命周期、拒绝结果及命中规则筛选。新记录不打断阅读位置，流量更新不改变排序；详情返回保留条件和位置。
- **暂停刷新**：冻结列表与详情的展示快照，不停止接管或观察；继续时同步最新观察，不播放积压。停止、未知和过期提示不受暂停掩盖。
- **反馈与布局**：操作立即反馈，成功以实际确认结果为准；错误提供恢复办法。长名称、窄屏、大字体、空数据和失败状态均需可用，不能仅检查正常截图。
- **动效与可访问性**：动效不延迟操作、不制造假流量，旧回调不能覆盖新状态；支持减少动效。确认运行后波纹从按钮边缘逐圈发出；停止时不发新圈，已有圈继续向外扩散，同时在约 1.5 秒内淡出，不冻结半径或等待完整扩散周期，不把收尾当作仍在运行。文字先退后进，避免叠字与同值重复动画；后台、覆盖或不可见时停止无意义动效。控件具备语义标签、足够对比度与可达操作，不能只靠颜色表达状态。
- **平台适配**：手机、大屏和桌面按空间与输入方式调整，不简单放大手机版。具体材质、尺寸和动效以原型为参考，在真实界面中验证，不冻结为逐项复制的规格。

原型采用模拟数据，不联网、接管或持久化；总览、策略和连接方向已认可，配置流程仍需操作评审。原型未完成，不继续把 HTML 扩展为第二个生产客户端。

## 5. 数据真实性与隐私

- 连接、单次 HTTP 请求和复用连接上的请求不是同一单位；不承诺查看每次加密请求内容。
- 连接快照只能形成观察历史。短连接或拒绝可能漏采；没有事件来源时，不承诺精确结束时间、结束原因或最终流量。采样差分速度是区间平均值，不是精确瞬时值。
- 活跃/结束与允许/拒绝是不同维度。实际策略链不能被组的最新选择覆盖；域名缺失不编造 URL，目标 IP 不等于出口公网 IP。
- 未知、过期、未测和零值分别表达；不补造缺失采样或曲线峰值。延迟测试缺席结果不一律判为超时，协议或 UDP 能力不等于实测可用。
- 应用名称、图标、地区和其他字段必须有实际来源，不能从名称或字段存在推导能力。无法取得时明确未知或不可用。
- 不增加没有数据来源的 MitM、请求/响应内容或阶段计时栏目。历史保留范围、容量和期限单独确定，不无限保存。
- 配置 URL、节点凭据和诊断记录可能含敏感信息；默认脱敏，复制/导出说明内容与风险，不使用私人订阅作为原型测试材料。

## 6. 实施前待决定

- 平台接管、后台、异常阻断、always-on/lockdown、开机恢复与 HTTP 代理建议的行为和支持边界。
- 外部资源准备、DNS/UDP/IPv6、协议及平台版本兼容范围。
- 策略编辑、复写的数组/覆盖/删除语义及失败处理。
- 完整连接/拒绝采集、应用归属、跨重启历史与资源更新时间的来源。
- 更完整的内核运行缓存管理、许可与发布要求；每配置策略偏好的规则已在上文明确。

只在对应功能实施前决定，不让候选方案或测试做法自行变成产品承诺。
