评审步骤与反馈
  • 选择“未导入配置”，完成导入 → 启动 → 切换模式 → 关闭；检查状态、配置与模式、上下行读数是否沿同一阅读顺序衔接。
  • 运行时观察盾牌图标底色呼吸与联动扩散波纹：卡片底色、文字和按钮保持静止。启停与核实时箭头旋转；模式与导入仅在对应区域反馈等待。
  • 下载、上传各配一条紧凑趋势，共用最近 30 秒窗口与采样读数。各图独立尺度，不能按曲线高度比较速度大小。
  • 运行时每秒回放预设示例采样，非真实监测；有效采样到来时端点产生小波纹，零值也包括在内。历史选点跟随同一采样，移出窗口后提示重选；可暂停回放检查。
  • 从总览配置区进入配置管理：首次导入选择当前，后续只保存候选；运行中切换先校验再停止、启动，当前更新成功也停止后启动。更新失败停止且旧内容不可启动；停止后删除当前选择剩余第一项，不自动启动。
  • 从策略网格打开成员面板，检查选择成功／失败、子组成员摘要与独立延迟、自动固定与恢复自动。测试未返回不等于超时；自动组“恢复自动并测试”会先解除固定，即使测试失败也不恢复。
  • 连接按查看范围与规则筛选，每秒刷新；可临时暂停展示，观察仍继续，不暂停总览采样。新记录自动加入并保护阅读位置；历史只有最后观察值，没有精确结束时间。
  • 检查失败、授权取消、未知、长名称、大字号及减少动效。宽窗口仅检查网格重排；完整大屏工作区、Flutter Web 与真实网络不在本轮范围。

状态优先的整合候选：配置与模式在同一区域，上下行数字各配紧凑趋势，共用窗口与采样读数。布局、材质及动效参数并未定案。

所有授权、配置校验、状态与速度均为模拟；不会联网、启动 VPN 或存储订阅。运行时每秒循环回放预设示例，固定最近 30 秒，不是实际网络监测。各图独立尺度，曲线高度不可直接比较速度。

盾牌图标底色呼吸与扩散波纹默认开启，可关闭；它表达服务运行，不代表流量。有效采样到来时端点产生一次小波纹，包括零值，不对未知／缺失数据产生波纹。局部模式与导入操作不改变服务运行表现，启停／核实时使用旋转等待。

停止、未知、异常、不可见和减少动效时不播放盾牌波纹。减少动效仍每秒更新数据；页面隐藏暂停回放，恢复后不补造数据。可暂停模拟采样检查；历史选点跟随同一采样，移出窗口后提示重选。异常阻断仅为已知状态示意，不承诺整个进程死亡后保持阻断。

策略网格与成员面板、连接列表与详情使用固定 mihomo v1.19.32 的数据语义。连接是快照观察，不是 HTTP 请求数据库；拒绝为预设样例，完整采集与 Android 应用归属仍需额外集成。

所有页面均为模拟，不提供 MitM、请求／响应内容、精确结束事件或阶段计时。完整大屏布局、Flutter Web 和真实网络不在本轮范围；浏览器效果不能证明 Flutter 渲染、Android 性能或网络可靠性。
